# 試作：第1章 金融（状態とルールで動く）

ブラウザで `index.html` を開くと遊べます（サーバー不要）。

- `engine.js`：月ごとの国の動きと、条件で出るイベントの選び方（遅れて出る効果、冷却期間、乖離度）
- `events.js`：イベントの部品。`when`（起きる条件）と `choices`（選択肢と、値の変化）だけで書く
- `test.js`：方針ごとに最後まで自動で動かし、結果が分かれるか確かめる（`node test.js`）
- `fuzz.js`：選択をランダムに3000回動かし、止まらないか・全イベントに到達できるかを確かめる（`node fuzz.js`）

## 試作で確かめていること
- 大きな事件（株価の底割れ）は、金融の傷みが一定以上になったときだけ起きる。早く手を打てば起きず、国が伸びる
- 手を打っても、規模が小さいと悪い事態が重なる（連鎖倒産 → 追加投入 → バッシング → 最後の決断 → 資金枯渇）
- 大量に投入すると連鎖は止まるが、批判 → 支持率低下 → 資金枯渇につながる
- 「史実の基準線」は、史実に近い選択を選び続けた同じ試作の結果

## 未調整
- 数値はすべて仮。現在の「史実」は第1章の期間（〜1993年）で見ると悪く出すぎている
- 選挙で落選しにくい
- イベントは関数で書いている。本番はデータ形式（JSON）にして、設計書の表から生成する想定
