# 試作：第1章 金融と政局（状態とルールで動く）

ブラウザで `index.html` を開くと遊べます（サーバー不要）。

- `engine.js`：月ごとの国の動きと、条件で出るイベントの選び方（遅れて出る効果、冷却期間、乖離度、世界の揺れ、予兆の流し方）
- `events.js`：イベントの部品。`when`（起きる条件）と `choices`（選択肢と、値の変化）だけで書く
- `omens.js`：予兆。情報源ごとの偏りを通して、隠れた値を少しずつ知らせる（状態は変えない）
- `app.js`：画面
- `policies.js`：自動プレイの方針（史実、早期処理、ドンの説得など）

自動プレイ、アーティファクトの組み立て、画面の動作確認は、共通の道具（`prototype/tools/`）を使います。

```
npm test                                                  # 方針ごとの通し試験 + ランダム3000回
npm run sim -- prototype/ch1-finance --trace 早期 --seeds 1  # 1手ずつ値を見る
npm run build -- prototype/ch1-finance 出力先.html          # アーティファクト用に1枚にまとめる
npm run smoke -- prototype/ch1-finance                    # ブラウザで押し続けてエラーを見る
```

## 試作で確かめていること
- 大きな事件（株価の底割れ）は、金融の傷みが一定以上になったときだけ起きる。早く手を打てば起きず、国が伸びる
- 手を打っても、規模が小さいと悪い事態が重なる（連鎖倒産 → 追加投入 → バッシング → 最後の決断 → 資金枯渇）
- 大量に投入すると連鎖は止まるが、批判 → 支持率低下 → 資金枯渇につながる
- 史実の出来事（ドンの辞職・逮捕、内閣不信任案、党の分裂）も、条件を満たさなければ起きない
- 「史実の基準線」は、同じ世界で史実に近い選択を選び続けた結果

## 「答えが分かっている」問題への対策
| 対策 | 仕組み |
|---|---|
| A 早すぎる正解には政治の代償 | 隠れた値「世論の危機認識」。本当の傷みに世論が追いつく前に手を打つほど、批判・求心力・地元の支持の損失が大きい。検査や投入そのものが、世論に危機を知らせる |
| B 遊ぶたびに世界が少し違う | 傷みの初期値・増え方・底割れの境目・ドンの疑惑の速さを、種から小さく揺らす。章の終わりに、今回の世界の条件を明かす |
| C 正しい政策が人を裏切る | ドンは公的資金に反対。反対中は必要な求心力が上がり、押し切ると関係と資金を失う。手帳で説得（借りが残る）、裏金リストで脅す（スキャンダル）、父の死の夜の真相で問いただす、失脚を待つ、の道がある |

## 選択の場面で見せる事情（V-13）
イベントの文章の下に、国・国民・企業の事情を並べる。

| 立場 | 数字 | 言い分の例 |
|---|---|---|
| 国 | 財政収支（兆円/年）、税収、成長率 | 大蔵省の主計局長、銀行局長 |
| 国民 | 失業率、暮らしの実感 | 街の声、商店街の会長、失業した元工員 |
| 企業 | 倒産（件/月）、日経平均 | 頭取、建設会社、電機メーカー、経済団体 |

- 数字には3か月前との比較（↑↓→）を付ける。イベントが言い分（`voices`）を持たなければ、数字から一言を作る
- 数字は内部の値（景気、金融の傷み、連鎖倒産、歳出）から換算した表示用の値（`engine.js` の `indicators`）。史実の統計とは一致させていない
- 財政を傷める選択は、その分だけ単年度の歳出（`spend`）を増やし、時間とともに戻る
- 赤字が年12兆円を超えると、大蔵省が増税か歳出削減を迫る（`mofPress`）

## 順調すぎるときの出来事と語り部（設計要件書の14.6）
| 出来事 | 型 | 起き方 | 備え・予兆 |
|---|---|---|---|
| 物価の高騰 → 暴動 | 1：成功が生む問題 | 景気の過熱と、景気が良いときの歳出の膨張で物価の圧力（`infl`）が上がる。物価上昇率4.5%で高騰、6%（暮らしが悪ければ5%）で暴動 | 予兆「物価」。利上げや歳出の削減で抑えられる |
| 首都の大水害 | 2：外からの衝撃 | 語り部（`chance`）が起こす。9か月目以降、波乱のない月が8か月を超えると、月ごとの確率が上がる | 防災力（`bousai`）で被害が3段階に変わる。治水計画への投資で上がり、歳出の削減で下がる。予兆「河川局」 |

- 史実にない出来事（`invented: true`）での選択は、乖離度を上げない
- 波乱にあたるイベント（`tension: true`）が起きると、語り部の平穏の月数が0に戻る
- 選ぶ前に起きてしまう被害は `onStart` で出す
