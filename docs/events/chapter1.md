# 第1章 イベント設計：バブル崩壊と父の遺産（1991年4月〜1993年8月）

- 版：v0.2（人物設定書の決定〈ドンの辞職は必ず起き、逮捕は分岐する／父の死の夜の密談が章の縦糸〉を反映）
- 前提：設計要件書（`docs/design-requirements.md`）の第13〜17章
- 乖離度：史実の選択と違う選択をすると、乖離度が上がる（Z-6）。各イベントの「史実の選択」が判定の基準になる
- 範囲：チュートリアル（1990年12月〜1991年4月、第10章）の後から、1993年の衆議院選挙まで

---

## 1. 章の概要

### 1.1 テーマ
- 父の時代（昭和・バブル）の後始末をしながら、党の新人議員として足場を固める
- 章の終わりに、**党が割れるかどうか**（史実の1993年の政権交代）という大きな分岐が来る

### 1.2 章の中のプレイヤーの立場
| 時期 | 立場 | できること |
|---|---|---|
| 1991年4月〜 | 新人議員 | 陳情の処理、党の会議での発言、派閥内の投票 |
| 1991年11月〜（総裁選の結果次第） | 政務次官 | 担当省庁の小さな政策に関わる。予算編成で担当分野の陳情を通しやすくなる |
| 1992年以降（条件次第） | 党の部会長、または派閥の幹部 | 担当分野の法案の中身に関わる。派閥の跡目争いに加われる |

第1章では大臣にはならない（大臣と組閣は第2章以降）。

### 1.3 仮の名前
実在の名前を避けるため（X-1）、以下の仮の名前を使う。最終的な名前は未決。
| 仮の名前 | 役割 | 史実のモチーフ |
|---|---|---|
| 民自党 | プレイヤーの所属する与党 | 1990年代初頭の与党 |
| ドン | 党の最高実力者。父の盟友で、派閥の会長 | 当時の党の最高実力者 |
| 北陽銀行 | 地元のメインバンク | 不良債権を抱えた地方銀行 |
| 大手運送会社 | ドンへの巨額献金で問題になる企業 | 当時の献金事件 |

### 1.4 章の流れ
```
1991年4月  初登院（チュートリアル終了）
   │
   ├─ メインクエスト：北陽銀行の不良債権（3段階）
   ├─ 外交：湾岸戦争の後始末、半導体協定、北の超大国の混乱
   ├─ 党内：総裁選 → ポストの獲得
   │
1992年     株価の底割れ → 公的資金を早く入れるか（最大の分岐点の1つ）
   │       ドンの献金疑惑 → 議員辞職 → 派閥の跡目争い
   │       参議院選挙
   │
1993年     ドンの逮捕 → 政治改革を求める世論
   │       内閣不信任案（党が割れるかどうか）
   ▼
1993年7月  衆議院選挙 → 第1章の終わり
```

## 2. メインクエスト：北陽銀行の不良債権

チュートリアルの最後に届いた頭取の直訴状（第10章のステップ6）から始まる3段階のクエスト。**ここでの判断が、第2章・第3章の金融危機（金融機関の破綻）の規模を決める。**

### MQ-1 頭取の再訪（1991年6月）
- 種類：B（政治・経済の結果）
- 状況：北陽銀行の頭取が執務室に来る。「地価の下落で、融資先の不動産会社が返済できません。このままでは決算が持ちません」。北陽銀行は父の代からの後援会の柱でもある。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 大蔵省に口を利き、追い貸しを認めさせる | 地元の支持 ↑、金（献金）↑、しがらみ ↑ | 不良債権が隠れたまま膨らむ。MQ-3で破綻の規模が大きくなる |
| 大蔵省の検査を促し、損失を早めに表に出させる | 地元の支持 ↓↓、献金 ↓、しがらみ ↓ | 北陽銀行の経営危機が早まるが、損失は小さく済む |
| 他の銀行との合併を仲介する | 人と求心力を使う。地元の支持は変わらない | 合併先の能力次第で、MQ-3の結果が良くも悪くもなる |
| （何もしない） | 変化なし | 史実に近い。不良債権はゆっくり膨らむ |

- 史実の選択：追い貸しと問題の先送り（当時の金融機関全体の傾向）

### MQ-2 公的資金の早期投入論（1992年8月）
- 種類：B（政治・経済の結果）。**第1章で最大の分岐点の1つ**
- 状況：株価が1万4千円台まで落ちる。総理が「金融機関に公的資金を入れてでも、不良債権を処理すべきだ」と発言するが、銀行業界、財界、大蔵省、世論がそろって反発する。
- 発生条件：時期は固定。ただし、選べる選択肢はプレイヤーの求心力で変わる
- **投入規模を幅から選ぶ（V-7）**：投入するを選ぶと、規模を「1兆〜20兆円」の幅で決める。予測には、景気（GDP）の増減、救済へのバッシング、連鎖倒産の確率が、規模ごとに幅で表示される（D-2）

| 選択肢 | 必要な条件 | 効果 | 連鎖 |
|---|---|---|---|
| 総理を支持し、党内をまとめて公的資金の投入を実現する（規模を選ぶ。下の表） | 求心力 高 | 財政 ↓、党の支持率 ↓↓（「銀行救済」への反発）、業界団体の献金 ↓、乖離度 ↑↑ | 第2章・第3章の金融危機が小さくなる。失われた10年の流れを変える最大の分岐。代償として、次の選挙で不利になり、E1-17のバッシングを受ける |
| 投入に賛成するが、党内の大勢には逆らわない | ― | 求心力 ↑（改革派から）、世論 ↑ | 規模は小さく固定（下の表の「小」）。金融危機は少し小さくなる |
| 反対する（銀行業界と大蔵省の側に付く） | ― | 献金 ↑、しがらみ ↑ | 史実どおり。E1-18の連鎖倒産が時間差で起きる |

**投入規模ごとの結果（景気の増減はGDP、連鎖倒産は金融の傷みと合わせて判定）**

| 規模 | 目安 | 景気（GDP） | 救済へのバッシング | 連鎖倒産 | 財政 |
|---|---|---|---|---|---|
| 投入なし（史実） | 0 | 当面は ↑（痛みを先送り）、1995年以降 ↓↓ | なし | 先送りされ、1997〜98年に大型破綻（第2・3章） | 当面は ↑、後で ↓↓ |
| 小 | 1〜4兆円 | 短期 ↓（小）、中期 ↑ | 小 | 弱い銀行の一部だけ守る。取りこぼした銀行が連続して倒れる危険が中 | ↓ |
| 中 | 5〜12兆円 | 短期 ↓、中期 ↑↑ | 中〜大 | 大手と地方の主要行は守れる。連鎖倒産の危険が小 | ↓↓ |
| 大 | 13〜20兆円 | 短期 ↓↓（国民負担への反発で消費が冷える）、中期 ↑↑（金融が早く立ち直る） | 大（「銀行だけを救うのか」） | ほぼ止まる。ただし「何でも国が守る」と受け止められ、モラルハザード（緩み）が出る | ↓↓↓ |

- 小さすぎると、中途半端な救済で傷が残り、**救済したのに連鎖倒産が起きる**（E1-18）。大きすぎると、財政と党の支持率が先に傷む。ちょうどよい規模は、金融の傷み（MQ-1の結果と第2節の「金融の傷み」）で変わる。傷みが大きいほど、必要な規模は大きい
- 史実の選択：反発を受けて立ち消えになり、不良債権処理は1990年代後半まで先送りされた
- 通信簿での答え合わせの例：「あなたは1992年に約10兆円の公的資金の投入を実現しました。史実では立ち消えになり、金融機関の大型破綻は1997〜98年まで続きました」

### MQ-3 北陽銀行の行方（1993年春）
- 種類：B（政治・経済の結果）
- 状況：MQ-1とMQ-2の結果で内容が変わる

| これまでの結果 | 状況 | 選択肢の例 |
|---|---|---|
| 追い貸しをした | 損失が膨らみ、破綻寸前 | 地元経済を守るため救済を働きかける（金と求心力を大量に使う）／破綻させる（地元の支持 ↓↓）／事実を隠し続ける（スキャンダル ↑↑） |
| 検査を促した | 経営再建の途中 | 再建を支援する／自主的な再建に任せる |
| 合併を仲介した | 合併後の統合 | 合併先の能力が高ければ安定する。低ければ混乱する |

### E1-01 海の向こうの戦争の後始末（1991年4月）
- 状況：中東の戦争は終わったが、日本は巨額の資金を出しながら「金だけ出して人を出さない」と国際的に批判された。ペルシャ湾に残る機雷の除去に、自衛隊の部隊を出すかどうかを党の会議で議論している。新人議員として発言を求められる。

| 選択肢 | 効果 |
|---|---|
| 派遣を強く主張する | 国際関係（対米）↑、党の支持率 ±（世論が割れる）、タカ派の長老の評価 ↑ |
| 慎重論を述べる | 党内のハト派の評価 ↑、国際関係（対米）↓ |
| 派閥の方針に従う | 求心力 ↑（小）。他の変化なし |

### E1-02 半導体協定の更新（1991年6月）
- 状況：米国が、日本市場での外国製半導体のシェアを20%に引き上げるよう求めている。国内の半導体メーカーは世界の首位を争っている。
- 技術投資の「窓」（R-1）の最初のイベント。半導体の窓は1990年代前半に開いている。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 目標を受け入れる | 国際関係（対米）↑↑、技術力（半導体）↓ | 史実どおり、日本の半導体シェアは徐々に下がる |
| 受け入れつつ、国内メーカーの研究開発に予算を付ける | 財政 ↓、国際関係 ↑、技術力 ↑ | 窓が開いている時期の投資なので、効果が大きい |
| 受け入れを拒む | 国際関係（対米）↓↓、技術力 ↑ | 米国からの報復のイベント（関税など）が起きやすくなる |

### E1-03 大手証券の損失補填（1991年7月）
- 状況：大手証券会社が、大口の顧客にだけ株の損失を穴埋めしていたことが発覚する。補填を受けた企業の中に、父の後援会の企業がある。

| 選択肢 | 効果 |
|---|---|
| 規制の強化を主張する | 党の支持率 ↑、地元の支持 ↓（後援会の企業が反発）、献金 ↓ |
| 黙っている | 変化なし |
| 後援会の企業の名前が出ないよう動く | 金 ↑、しがらみ ↑、スキャンダル ↑ |

### E1-04 北の超大国の混乱（1991年8月）
- 状況：北の超大国でクーデターが起き、政権が揺らいでいる。北方の領土問題を動かす好機だという声がある。

| 選択肢 | 効果 |
|---|---|
| 経済支援と引き換えに、領土交渉を進めるよう主張する | 財政 ↓、国際関係 ±。交渉が成功する確率は低いが、成功すれば大きく評価される |
| 米国と足並みをそろえる | 国際関係（対米）↑ |
| 静観する | 変化なし |

### E1-05 党の総裁選（1991年10月）
- 状況：党の総裁（＝総理）が交代する。派閥の会長であるドンが、誰を担ぐかを決める。
- プレイヤーは派閥の一員として投票する。**第1章でポストを得る主な機会**

| 選択肢 | 効果 |
|---|---|
| ドンの決定に従う | 求心力 ↑、政務次官のポストを得やすい |
| 別の候補を推す若手の動きに加わる | 求心力 ↓（派閥内）、改革派の人材とのつながり ↑。勝ち馬に乗れば大きく評価される |
| 自分を推すよう根回しする | 現実的ではない。長老たちに「生意気な小僧」と睨まれる（求心力 ↓↓）。ただし話題にはなる（党の支持率 ↑） |

### E1-06 予算編成（毎年12月）
- 定期イベント（13.1）。第1章では、新人議員か政務次官として、陳情を予算に押し込めるかどうかを争う
- ランダムな陳情イベント（第4章）で集まった案件の中から、通すものを選ぶ

### E1-07 ドンの献金疑惑（1992年2月）
- 状況：大手運送会社からドンへの巨額の献金が報じられる。父もこの会社と付き合いがあった。
- **チュートリアルで裏金リストを「使う」か「封印する」を選んでいた場合**、捜査の手が父の裏金にも及ぶ可能性がある（スキャンダル ↑）

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| ドンを擁護する | 求心力 ↑（派閥内）、党の支持率 ↓ | ドンが逮捕されたとき、巻き込まれる危険がある |
| 距離を置く | 変化は小さい | ― |
| 捜査への協力や、党内での追及に回る | 党の支持率 ↑↑、求心力 ↓↓（派閥から敵視される） | 長老を見捨てて派閥を乗っ取るルートの入り口（E1-11） |

### E1-08 国際平和協力法案（1992年6月）
- 状況：国連の平和維持活動に自衛隊を参加させる法案。野党は牛歩戦術で抵抗している。
- 法案の重さ：中くらい（16.1）

| 選択肢 | 効果 |
|---|---|
| 賛成して成立させる | 国際関係 ↑、党の支持率 ±（世論が割れる） |
| 野党の要求を入れて修正し、合意で通す | 国際関係 ↑（小）、求心力 ↑（調整役として評価される）、人と時間を使う |
| 見送りを主張する | 国際関係 ↓、党内のタカ派の評価 ↓ |

### E1-09 参議院選挙（1992年7月）
- 定期イベント。結果は党の支持率で決まる（8.1）
- 負けると、第1章の残りがねじれ国会になり、重い法案が通しにくくなる（K-4）

### E1-10 株価の底割れと経済対策（1992年8月）
- 状況：日経平均が1万4千円台まで落ちる。党は大型の経済対策を作る。直後にMQ-2（公的資金の早期投入論）が続く。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 公共事業を中心にした大型の対策 | 景気 ↑（短期）、財政 ↓↓、地元の支持 ↑（建設業界） | 史実どおり。効果は数年で切れる |
| 減税を中心にした対策 | 景気 ↑（小）、暮らしの実感 ↑、財政 ↓↓ | ― |
| 小規模にとどめ、財源を不良債権の処理に回すよう主張する | 景気 ↓（短期）、建設業界の献金 ↓ | MQ-2で公的資金の投入を実現しやすくなる |

### E1-11 ドンの議員辞職と派閥の跡目争い（1992年10月）
- **ドンの辞職はどのルートでも必ず起きる**（人物設定書の10.4）。献金の構造は父の代からのもので、新人議員には止められないため
- 状況：献金事件の責任を取ってドンが議員を辞める。派閥の会長の座をめぐって、古参の実力者と改革派の若手リーダーが争う。
- **元の構想にある「長老を見捨てて派閥を乗っ取る」快感の山場**

| 選択肢 | 必要な条件 | 効果 | 連鎖 |
|---|---|---|---|
| 古参の実力者に付く | ― | しがらみ ↑、求心力 ↑（派閥内） | 派閥は保守派が握る。E1-13で党は割れにくい |
| 改革派の若手リーダーに付く | ― | 党の支持率 ↑、古参からの評価 ↓ | 派閥が割れる。E1-13で党が割れる確率が上がる |
| 自ら跡目に名乗りを上げる | 求心力 高、人（議員）が一定数 | 成功すれば派閥の会長になる（第1章の最大の出世）。失敗すれば求心力 ↓↓ | 自分の派閥として、E1-13の行方を左右できる |

### E1-12 ドンの逮捕（1993年3月）
- **条件次第で起きる**（人物設定書の10.4）。E1-07で捜査への協力や追及に回った、裏金リストを「清算」した、仁科が裏切りの段階3に達した、党の支持率が一定以下、のどれかを満たすと起きる。どれも満たさなければ、このイベントは「ドンの院政」に置き換わる（政治改革の世論は弱まり、しがらみ ↑↑、求心力 ↑（ドン派から））
- 史実の選択は「逮捕される」なので、逮捕を防ぐと乖離度 ↑
- 逮捕されたとき主人公がどこまで巻き込まれるかは、E1-07の選択と裏金リストの扱いで決まる（人物設定書の10.4の表）
- 状況：ドンが脱税の容疑で逮捕され、隠していた巨額の資産が見つかる。世論が激しく怒り、「政治改革」（選挙制度や政治資金の改革）を求める声が高まる。
- E1-07で擁護していた場合は、スキャンダルが大きく上がる

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 政治改革の法案を党内で推し進める | 党の支持率 ↑、長老からの評価 ↓↓ | 党内で改革がまとまれば、E1-13で党は割れない |
| 党の結束を優先し、改革は先送りする | 求心力 ↑（長老から）、党の支持率 ↓↓ | 史実に近い。E1-13で党が割れる確率が上がる |
| 何もしない | 党の支持率 ↓ | ― |

### E1-13 内閣不信任案（1993年6月）
- 種類：B。**第1章の山場**
- 発生条件：W-11（離党・新党の条件）を使う。党の支持率、派閥の対立、政治改革の進み具合、スキャンダルの量で、党が割れるかどうかが決まる
- 党が割れる条件を満たした場合：

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 不信任案に反対し、党に残る | 求心力 ↑（党内） | 党は割れたまま選挙へ。議席が大きく減り、下野の可能性が高い |
| 不信任案に賛成し、離党して新党を作る（W-10） | 党首になる。金と人を大量に使う | 新党として選挙に挑む。連立政権に入れる可能性がある |
| 採決を欠席する | 変化は小さい | 両方から信用されない（求心力 ↓） |

- 党が割れる条件を満たさなかった場合：不信任案は否決され、党は一体のまま衆議院選挙を迎える（史実からの大きな分岐）

### E1-14 衆議院選挙（1993年7月）
- 定期イベント。結果は8.1の段階制で決まる
- 史実：与党が過半数を割り、野党の連立政権が誕生した
- 選挙の結果で第2章の始まり方が変わる（与党のまま／下野／新党として連立入り）

### E1-15 未完の手帳（1991年7月）
- 種類：C（決まった時期に起きる）。人物設定書の10.6
- 状況：仁科と父の遺品を整理していると、書きかけの手帳が出てくる。銀行の不良債権を早めに処理する構想が、父の字でびっしり書かれている。日付は倒れる前の週で止まっている。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 早瀬に読ませる（早瀬を雇っている場合だけ） | 早瀬の忠誠 +5 | MQ-2の予測の幅が狭くなる。MQ-2の「公的資金の投入を実現する」に必要な求心力が「高」から「中〜高」に下がる |
| 自分で読み、仁科に預ける | 仁科の忠誠 +5 | MQ-2の「公的資金の投入を実現する」に必要な求心力が「高」から「中〜高」に下がる |
| 封印する | 変化なし | 史実どおり。MQ-2の条件は変わらない |

### E1-16 父の死の夜の真相（1993年3月、E1-12の前後）
- 種類：C（決まった時期に起きる）。**第1章の縦糸の山場**（人物設定書の第3章、10.5）
- 状況：父が倒れた赤坂の料亭での密談の相手は、ドンだった。中身は未完の手帳の構想で、ドンは反対していた。それを知るのは付き添っていた仁科だけ。死因は病死のままで、陰謀ものにはしない
- 知る経路は仁科の忠誠で決まる

| 経路 | 時期 | 効果 |
|---|---|---|
| 仁科の口から聞く（忠誠50以上） | E1-12（逮捕が起きなければ「ドンの院政」）の直前 | 下の3つから選べる |
| 週刊誌の記事で知る（忠誠50未満） | E1-12の直後 | スキャンダル ↑（父の名前が出る）、地元の支持 ↓。「公表する」は選べない |

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| ドンに問いただす | ドンが逮捕されていれば変化は小さい（面会で本音を聞くだけ）。逮捕されていなければ口止めの取引を持ちかけられ、受けると金 ↑、しがらみ ↑ | ドンの死（第3章のP-1）の告白の中身が変わる |
| 胸にしまう | 仁科の忠誠 +10 | ― |
| 公表する（仁科から聞いた場合だけ） | 党の支持率 ↑、ドン派からの求心力 ↓↓、仁科の忠誠 −10、乖離度 ↑ | E1-13で党が割れる確率が上がる |

### E1-17 救済へのバッシング（MQ-2の直後。公的資金を入れた場合だけ）
- 種類：B（条件次第）。MQ-2で「投入を実現する」を選んだ場合に起きる
- 状況：新聞の見出しが「銀行を税金で救うのか」に変わる。街頭では、住宅ローンの返済に苦しむ人が声を上げる。一方で、救済から外れた中小の取引先や、経営努力をしてきた同業の他行からも「なぜあの銀行だけ」と不満が出る。党本部には抗議の電話が鳴り止まない。仁科が言う。「先生、お父上は『正しいことは、たいてい嫌われる』と仰いました」。
- バッシングの大きさは、MQ-2の規模と、救済の条件（経営陣の責任、配当の制限）で決まる

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 経営陣の責任追及と、給与・配当の制限を条件にする | 党の支持率 ↑（バッシングが和らぐ）、業界団体の献金 ↓↓、しがらみ ↓ | 銀行業界が反発し、E1-18の協力が得にくくなる。モラルハザードが小さくなる |
| 条件を付けず、早く資金を入れて混乱を抑える | 党の支持率 ↓↓、金融の傷み ↓、業界団体の献金 ↑ | 救済は速いが、「銀行だけが得をした」という不信が残る。緩みが上がる |
| 中小企業向けの資金繰り支援も同時に出す | 財政 ↓、党の支持率 ↑（小）、地元の支持 ↑ | 「銀行だけ」の批判が和らぐ。財政の負担が増える |
| 説明の場に自ら立ち、党の会議と街頭で語る | 求心力 ↑（小）、スキャンダル → 、党の支持率 ↑（小） | 時間と人を使う。効果は穏やか |
| （何もしない） | 党の支持率 ↓（小） | バッシングが長引き、次の選挙（E1-14）に響く |

- 史実の選択：投入そのものが実現しなかったため、起きなかった
- 民間企業の救済を、特定の企業や人を名指しして描かない。バッシングは「世論」「他の銀行」「取引先」の反応として出す

### E1-18 連鎖倒産（MQ-2の1〜2年後。条件次第）
- 種類：B（条件次第）。投入しなかった場合は時間差で、投入が小さすぎた場合は取りこぼしの形で起きる
- 状況：弱い銀行が倒れると、その銀行から借りていた不動産会社が倒れ、その下請けの建設会社や商店が倒れる。取引先の信用不安が次の銀行に飛び火する。北陽銀行の頭取が青ざめて来る。「先生、うちの取引先の4社が、同じ週に手形を落とせません」。
- 起きる条件：MQ-2で「投入なし」、または規模が金融の傷みに対して小さすぎた場合。傷みが大きいほど、連鎖は長く、深い

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 連鎖を止めるため、追加の資金と預金の保護を急ぐ | 財政 ↓↓、景気 ↑（中期）、党の支持率 ↓ | 連鎖は止まる。「最初から入れていれば」という声が出る（乖離度 ↑） |
| 破綻した銀行を整理し、健全な銀行に営業を引き継がせる | 求心力 ↑（改革派から）、景気 ↓（短期）、失業 ↑ | 連鎖は局所に収まる。地元の支持 ↓（北陽銀行が対象なら↓↓） |
| 取引先の中小企業にだけ、つなぎの融資を出す | 財政 ↓、地元の支持 ↑、景気 ↑（小） | 銀行は倒れるが、実体経済の傷は浅くなる |
| （何もしない） | 景気 ↓↓、暮らしの実感 ↓、金融の傷み ↑↑ | 連鎖が続き、第2章・第3章の金融危機が大きくなる |

- 連鎖倒産の長さ（件数）は、金融の傷み、投入規模、E1-17の条件（モラルハザード）で決まる
- 史実の選択：先送りされ、1997〜98年に大手銀行・証券の破綻が続いた（第2・3章）
- 倒産する会社や人を駒として描かず、国のパラメーター（景気、失業）と地元の支持への影響として出す

### MQ-2の展開：救済局面（E1-17〜E1-21の進め方）
MQ-2の後は、内部の状態「**救済局面**」で進む。固定のストーリーではなく、局面ごとにプレイヤーの選択が入り、途中で別のルートに移れる。

**内部の値（隠れた値。画面には予測の幅として出す）**
| 値 | 初期値 | 役割 |
|---|---|---|
| 投入累計 | MQ-2の規模 | 追加投入のたびに加算。史実の基準線との比較にも使う |
| 金融の傷み | MQ-1の結果と第2節 | 連鎖倒産の長さを決める。投入で下がり、倒産で上がる |
| 救済への批判 | 0 | 世論、他行、取引先の批判の量。投入規模とE1-17の条件で上がり、時間とともに薄れる（反発の薄れ） |
| 資金調達力 | 100% | 企業献金とパーティ収入の倍率。批判と党の支持率が下がると減る |

**逐次投入の割増**：同じ合計額でも、小さく何度も入れると、1回で入れるより効果が出にくく、費用がかさむ。2回目以降の投入は、同じ額の効果を7割とみなし、救済への批判を1回ごとに加算する（「また税金か」）。

**ルート①：逐次投入の泥沼（小さく入れる → 止まらない → やけくそ）**
| 局面 | イベント | 何が起きるか | 抜け道 |
|---|---|---|---|
| 1 | MQ-2（規模 小） | 一部の銀行だけが守られる | ― |
| 2 | E1-18 連鎖倒産（1回目） | 取りこぼした銀行から倒産が広がる | 追加投入／破綻整理／つなぎ融資 |
| 3 | E1-19 追加投入の判断 | 追加で入れると、批判が加算される。倒産は減るが止まりきらない。2回目、3回目と繰り返せる | 破綻整理に切り替える（ルート③） |
| 4 | E1-20 マスコミバッシング | 連続投入への批判が頂点に。「見通しの甘さ」が追及され、求心力 ↓↓ | 責任を取る（役職を辞する）／一気に決断する |
| 5 | E1-20 最後の決断（やけくそ投入） | 一気に大規模を入れる。連鎖は止まる | ― |
| 結果 | | 財政 ↓↓↓、党の支持率 ↓↓、求心力 ↓、緩み（モラルハザード）↑、スキャンダル ↑（小）。ただし金融の傷みは大きく下がり、第2章の景気の出発点は意外に悪くない | |

**ルート②：大量投入の代償（一気に入れる → 止まる → 批判と資金難）**
| 局面 | イベント | 何が起きるか | 抜け道 |
|---|---|---|---|
| 1 | MQ-2（規模 大） | 連鎖倒産はほぼ止まる。景気は中期で ↑↑ | ― |
| 2 | E1-17 救済へのバッシング | 「銀行だけ救うのか」が止まらない。他企業、取引先、同業から | 条件を付ける／中小支援を足す／説明に立つ |
| 3 | 支持率の低下 | 党の支持率 ↓。批判が薄れる前に次の局面が来る | ― |
| 4 | E1-21 資金の枯渇 | 企業献金とパーティ収入が大きく減る（資金調達力 ↓）。選挙資金が足りない | 下の表 |
| 結果 | | 金融と景気は立ち直るが、政治資金の不足が選挙（E1-14）に響く。裏金への誘惑（第10章の裏金リスト）が直接来る | |

**ルート③：破綻整理に切り替える**：ルート①の局面3で、投入をやめて破綻整理へ移る。傷みが大きいと景気 ↓↓ だが、救済への批判は消え、求心力は戻る。地元の支持はMQ-1の結果で決まる。

### E1-19 追加投入の判断（E1-18の後。逐次投入の場合）
- 種類：B。何度でも繰り返せるが、回を重ねるほど割増が効く
- 状況：総理は言う。「あと少しで止まる」。だが党内の声は割れる。「ここで止めたら、これまでの金は無駄になる」「いや、もう止めよう」。大蔵省の担当者は、追加の額を数字で示す。前回より大きい。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 追加で投入する（額を幅で選ぶ） | 財政 ↓、救済への批判 ↑、金融の傷み ↓（小） | 倒産は減るが止まりきらない。回数が増えるほど割増。3回目でE1-20に進む |
| 一気に大規模に切り替える | 財政 ↓↓、救済への批判 ↑↑ | E1-20の最後の決断を前倒しする。割増はなくなる |
| 投入を打ち切り、破綻整理に移る | 景気 ↓↓（短期）、救済への批判 ↓、求心力 ↑（小） | ルート③。金融の傷みが大きいと連鎖が続く |
| （何もしない） | 金融の傷み ↑ | 倒産が続く。E1-20が早まる |

### E1-20 マスコミバッシングと最後の決断（逐次投入が3回に達した場合）
- 種類：B。**ルート①の山場**
- 状況：週刊誌と夕刊の見出しが一斉に変わる。「泥沼」「見通しの甘さ」「税金の垂れ流し」。国会では野党が追及し、与党の若手が執行部に批判を向ける。仁科が小声で言う。「先生、ここが一番、人の本性が出ます」。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 一気に大規模な投入を決断する（やけくそ投入） | 財政 ↓↓↓、党の支持率 ↓↓、求心力 ↓、緩み ↑ | 連鎖は止まる。パラメーターが大きく変わった状態で第2章へ |
| 責任を取り、担当の役職を辞する | 求心力 ↓↓、スキャンダル → 、乖離度 ↑ | 後任が決断する。主人公の責任は薄れるが、第2章の序盤は党の傍流で始まる |
| 破綻整理に切り替え、痛みを引き受ける | 景気 ↓↓、求心力 ↑（改革派から）、党の支持率 ↓ | ルート③。傷みが大きいほど、景気の落ち込みが深い |
| （何もしない） | 党の支持率 ↓↓、金融の傷み ↑ | 倒産が続き、総理の退陣が早まる |

### E1-21 資金の枯渇（E1-17の後。大量投入の場合）
- 種類：B。**ルート②の山場**。資金調達力が下がり切った時点で起きる
- 状況：財界の会合から、主人公の名前が消える。「銀行を救った政権に出す金はない」「救われなかった側が怒っている」。パーティ券の売れ行きが半分になり、企業献金の約束が次々に取り消される。事務所の金庫は、選挙費用を前に細っていく。鬼塚が帳簿を持ってくる。「先生、このままでは選挙が持ちません」。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 経費を削り、後援会の個人献金と小口のパーティで回す | 金 ↓、地元の支持 ↑（小）、しがらみ ↓ | 苦しいが、きれいなまま乗り切る。選挙は厳しい |
| 派閥の長老に頭を下げ、資金を借りる | 金 ↑、しがらみ ↑↑、求心力 ↓（借りを作る） | 派閥への借りが残る。第2章の人事に響く |
| 机の中の裏金リストに手を出す（第10章） | 金 ↑↑、スキャンダル ↑↑ | 資金は戻るが、予兆（G-1）が始まる。E1-12・E1-16と重なる |
| 献金に頼らず、政党交付金の議論（政治改革）を進める | 党の支持率 ↑（小）、金 ↓、求心力 ↑（改革派から） | E1-13の政治改革のイベントと結びつく。ドン派の反発 |
| （何もしない） | 金 ↓↓、地元の支持 ↓ | 選挙でその分が響く |

- 資金調達力は、救済への批判が薄れ、党の支持率が戻ると、年ごとに回復する（反発の薄れ）

## 4. 日常の案件（ランダム）

種類C。第1章の間に、パラメーターに応じた出やすさでランダムに起きる。

| 案件 | 出やすくなる条件 | 選択肢の例 |
|---|---|---|
| 農協の陳情（牛肉・オレンジの輸入自由化の補償） | 選挙区が地方 | 補助金を通す／断る／条件付きで通す |
| ゴルフ場開発の口利き（バブルの名残） | しがらみが高い | 引き受ける（金 ↑、スキャンダル ↑）／断る |
| 後援会の企業が地価の下落で倒産寸前 | 景気が悪い | 金を貸す／銀行を紹介する／見捨てる |
| パーティー券の購入依頼 | 求心力が低い | 引き受ける（金 ↓、求心力 ↑）／断る |
| 長老からの料亭での会食の呼び出し | 派閥内の立場が低い | 出席する（時間と金 ↓、求心力 ↑）／断る |
| 父についての怪文書 | 裏金リストを処理していない | 調べる（人を使う）／放置する（スキャンダル ↑） |
| 週刊誌の取材 | スキャンダルが33以上 | 応じる／断る／金で黙らせる |
| 後援者の冠婚葬祭 | 地元の支持が低い | 出席する（金 ↓、地元の支持 ↑）／秘書に代理を頼む |
