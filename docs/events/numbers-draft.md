# 数値の初期案（全章共通）

- 版：v0.1（初版。未決事項の整理（`events/open-issues.md`）の第3節「後で数値を決めること」の初期案）
- 前提：設計要件書（`docs/design-requirements.md`）の15章（パラメーター）、16章（法案と議席）、17.3（乖離度）、第1〜8章と「別の歴史」（`events/z10-alternate-history.md`）のイベント設計
- 位置づけ：**試作で調整するための出発点**。確定ではない。ここにある数値は、イベント設計に書いた ↑ ↓ の記号を、あとでプログラムの値に直すための換算表になる
- 方針：イベント設計の文章は変えない。↑ ↓ は、この換算表で値にする。個別のイベントだけ値を変えたいときは、その章の表に「（値：○）」と書き足す

## 1. ↑ ↓ の換算

### 1.1 基本の換算（0〜100のゲージ）
| 記号 | 変化量 | 使いどころの目安 |
|---|---|---|
| （小）↑ ↓ | ±2 | 付け足しの効果、遅れて出る小さな反応 |
| ↑ ↓ | ±5 | ふつうの選択の効果 |
| ↑↑ ↓↓ | ±10 | 大きな決断（公的資金、増税、解散など） |
| ↑↑↑ ↓↓↓ | ±18 | 章の山場の決断。1章に数回まで |

- 「（短期）（中期）（長期）」付きは、同じ量を **短期＝即時、中期＝1〜2年かけて、長期＝3年以上かけて** 反映する
- 「（○○から）」付き（例：求心力 ↑（長老から））は、その派閥・層の内訳として動く。全体の値には、内訳の合計が半分だけ反映される（1つの選択で全体が動きすぎないようにする）

### 1.2 パラメーターごとの重み
同じ ↑ でも、動きやすさはパラメーターで違う。1.1の変化量に次の倍率をかける。

| パラメーター | 倍率 | 理由 |
|---|---|---|
| 地元の支持、求心力、スキャンダル、しがらみ（プレイヤー個人） | ×1.0 | 基準 |
| 党の支持率 | ×0.8 | 全国は動きにくい |
| 景気、暮らしの実感、技術力、国際関係、産業ごとの状態（国家） | ×0.5 | 国は大きく、1つの選択では動きにくい。複数年の積み重ねで効く |
| 財政 | ×0.5（増減は「GDP比」に換算して、1.5節の式） | 同上 |
| 人口 | ×0.2（遅れて出る効果の合計） | 人口の窓の効果は第7〜8章に遅れて出る（L-2、L-3） |
| 金（億円） | ゲージではなく数値（1.3節） | |

### 1.3 金（億円）の換算
| 記号 | 変化量 | 
|---|---|
| 金 ↓（小） | −3億 |
| 金 ↓ | −10億 |
| 金 ↓↓ | −40億 |
| 金 ↓↓↓ | −150億 |
| 金 ↑ ほかの記号は同じ量の逆 |

- 開始時の金の初期値の目安：出自ごとに50〜300億。選挙1回の費用の目安：選挙区30億、全国の応援を加えると100億
- 物価・景気の影響は考えない（章ごとに倍率をかけない）。ただし第4章以降の政治資金の規制（E4-24）で、集められる金の上限が下がる

### 1.4 上限と下限、時間の経過
| 項目 | 決まり |
|---|---|
| 範囲 | すべてのゲージは0〜100に収める（超えた分は捨てる） |
| 自然な戻り | スキャンダルは1年ごとに−3。地元の支持は、何もしなければ1年ごとに−2（選挙区の世話をしないと下がる）。求心力は戻らない |
| 党の支持率 | 1年ごとに、50に向かって差の1割だけ戻る（高い人気も低い人気も続かない） |
| 反発の薄れ | 設計要件書のK-6。反発の影響は1年ごとに2割ずつ薄れる（選挙の1年以内は薄れない） |
| 遅れて出る効果（V-8） | 「中期」は発生の翌年から2年、「長期」は発生の3年後から5年で反映する |

### 1.5 財政と景気の実数への換算（Q-1）
| ゲージ | 画面での表示 | 換算の初期案 |
|---|---|---|
| 財政 | 政府債務（GDP比） | ゲージ50＝GDP比100%。ゲージが10上がるごとに−20ポイント（良くなる）。1990年は約60%、2026年の史実は約250% |
| 景気 | 日経平均、GDP | 日経平均は景気のゲージと世界の景気から計算する（式は試作で決める）。GDPの成長率＝（景気−50）×0.1% |
| 暮らしの実感 | 賃金、失業率 | 失業率＝2.5%＋（50−暮らしの実感）×0.06% |
| 人口 | 総人口、出生率 | 出生率＝1.5＋（人口のゲージ−50）×0.01。総人口は出生率と高齢化から年ごとに計算 |
| 人口（試作の換算） | 総人口、高齢化率、出生数 | 総人口＝12,410万人＋年30万人（1991年起点。第1章の間はまだ増える）。高齢化率＝12.6%＋年0.5ポイント。出生率＝1.54＋（人口のゲージ−50）×0.01。出生数＝総人口×0.98%×（出生率÷1.54）×（1−経過年×0.6%）で、1991年は約120万人 |
| 社会保障費（試作の換算） | 兆円/年 | 47兆円＋年2.4兆円＋（高齢化率−12.6）×0.8。第1章では年々増えるだけで、削る・増やす選択はまだない |
| 国民負担率（試作の換算） | % | 36.5%＋年0.3ポイント＋政策による上げ下げ（`burdenAdj`。消費税のイベントTX-1〜TX-5が動かす） |
| 平均年収・手取り（試作の換算） | 万円/年 | 平均年収＝460万円＋（景気−56）×1.5＋（暮らしの実感−56）×1.0。手取り＝平均年収×（1−国民負担率×0.0065） |
| 家計の資産（試作の換算） | 兆円 | 1,700兆円＋（日経平均−31,000円）×0.03兆円−（金融の傷み−25）×5＋年30兆円。表示だけで、他の値にはまだ効かない |

## 3. 乖離度

### 3.1 加算の量（Z-6）
各イベントには、**史実の選択**と **重要度**（小・中・大）がある。史実と違う選択をしたとき、重要度で乖離度が上がる。

| 重要度 | 加算 | 目安 |
|---|---|---|
| 小 | +1 | 付け足しの選択、史実と違うが影響の小さいもの |
| 中 | +3 | 多くのイベント。表記の「乖離度 ↑」はここ |
| 大 | +6 | 表記の「乖離度 ↑↑」。章の山場 |
| 特大 | +12 | 表記の「乖離度 ↑↑↑」。大連立、郵政の見送り、政権を守る/失うなど、史実の国の形を変える決断 |

- 乖離度は下がらない（Z-7）。上限は100
- 同じ流れ（同じ原因）の連鎖で重ねて上がる分は、2回目から半分にする（雪だるま式に100に届くのを防ぐ）

### 3.2 段階の目安と、1周の想定
| 乖離度 | 状態 | 想定する到達点 |
|---|---|---|
| 0〜30 | 史実に近い | 第1〜3章を史実寄りに進めた人が、第4章で到達する範囲 |
| 30〜60 | ずれ始め | 積極的に変える人が、第4〜5章で到達する範囲 |
| 60〜100 | 別の歴史 | 総理になって大きく変える人が、第5〜6章以降に到達する。**章の途中で急に入らない**ように、60に達したら次の章の始まりから「別の歴史」を有効にする |

- 目安：総理になって史実とほぼ逆の選択を続けると、章あたり+15程度。第1〜8章の合計は100に届く。史実どおりに進めると、各章+1〜3で、合計20未満
- 第1章（4年）だけで30に届くことがないよう、**章ごとの加算の上限を+20**とする（上限を超えた分は次の章に持ち越さず捨てる）

### 3.3 「別の歴史」の流れの入口（Z-10の条件の補強）
`events/z10-alternate-history.md` の流れは、乖離度が60以上に加えて、次の条件で入る。

| 流れ | 条件 |
|---|---|
| ZA | 第3章の金融の傷みが「大」で、公的資金の投入が1年以上遅れ、1998年の参議院選挙で議席が過半数を大きく割った |
| ZB | 郵政の民営化を骨抜きにした、または風見が総裁選に敗れた後に、風見との関係が−40以下 |
| ZC | E5-10で大連立を受けた |
| ZD | 2009年の選挙で民自党が過半数を守った |
| ZE | 2012年と2014年の選挙の両方で民自党が政権に戻れなかった |

## 4. 法案と議席の数値（16章の補強）

### 4.1 求心力の段階
| 表記 | 求心力の値 |
|---|---|
| 低 | 20以上 |
| 中 | 40以上 |
| 高 | 60以上 |
| 非常に高 | 80以上 |

- 必要な議席の目安は設計要件書の16.1のとおり（軽い50%、中くらい55%、重い60%、非常に重い67%）
- 議席が足りていても、求心力が足りないと造反が出る（K-3）。足りない分の10ごとに、造反の議員が与党議席の2%ずつ増える
- 議席が目安より10ポイント以上多ければ、求心力の要件を1段階下げる（W-7に近い）

### 4.2 反発の大きさ
- 基本の反発：法案の重さが「重い」＝党の支持率−10、「中くらい」＝−5、「軽い」＝−2、「非常に重い」＝−14
- 倍率は16.3のとおり（景気が悪い2倍、1年以内2倍、公約に反する1.5倍、直後0.7倍、好況0.7倍）。重ねて適用し、**上限は4倍**
- 薄れ方は1.4節

### 4.3 選挙の結果の式（8.1の議席数）
| 項目 | 案 |
|---|---|
| 与党の議席の割合＝ | 基準値（前回の議席）＋（党の支持率−50）×0.6 ＋ 景気の効果 ＋ 野党の分裂の効果 − スキャンダルの効果（%ポイント） |
| 自分の選挙区の当落 | 地元の支持が40未満なら落選の危険（段階的）。20未満はほぼ落選。60以上でほぼ当選。三つどもえ・強敵（桐生など）の場合は、必要な値を+10する |
| 揺れ | 乱数ではなく、「風」（無党派の動き）を−10〜+10の値で別に持ち、イベントで決まる。1周目は史実の風の方向を使う |

## 6. 決断イベントの数と1周の長さ

### 6.1 イベントの数（現状）
章ごとのイベント数（`### E`の見出し）は、第1章16、第2章25、第3章25、第4章25、第5章22、第6章25、第7章32、第8章28。合計198。

| 章 | 期間（年） | イベント数 | 1年あたり |
|---|---|---|---|
| 1 | 約4 | 16 | 4.0 |
| 2 | 約4 | 25 | 6.3 |
| 3 | 約3.3 | 25 | 7.6 |
| 4 | 約5.4 | 25 | 4.6 |
| 5 | 約2.9 | 22 | 7.6 |
| 6 | 約3.3 | 25 | 7.6 |
| 7 | 約7 | 32 | 4.6 |
| 8 | 約7 | 28 | 4.0 |

- **第3・5・6章は、1年に7〜8個で、他の章の約1.7倍**。危機の章なので意図した密度だが、最速（1年＝1分）で進めると、ほぼ8秒に1回、時間が止まる
- 時間が止まるのは種類BとCだけにする（Aの災害とDの選挙・結果は、演出として流れる）。それでも1年あたり5〜6個

### 6.2 提案
| 案 | 内容 | 
|---|---|
| 案1（おすすめ） | イベントの数は変えず、**中間の倍率（2〜4分で1年）を既定にする**。最速は「慣れた人向け」とする。危機の章（3・5・6）は、既定の倍率でも「落ち着かない」感じを出す |
| 案2 | 第3・5・6章の「日常の案件」（各章の第4節）を、時間が止まらない自動処理（オート）に回し、止まるイベントを1年に4〜5個にする |
| 案3 | 第3・5・6章のイベントを、それぞれ20個まで減らす（約2割） |

- 総プレイ時間の目安：決断1回に30〜60秒かかるとして、198個で約2〜3時間。時間の進行（最速36分）を含めて、通しで3〜4時間。**周回を前提にした長さ**として妥当
- 試作は第1章（16個）から始める（設計要件書の「最初に作る範囲」の案：1990〜1993年）。第1章のテストで、決断1回あたりの時間と、1年あたりの個数の許容を測り、案1〜3を決める
