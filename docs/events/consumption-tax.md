# 消費税イベント（全章共通）

- 版：v0.1（たたき台）
- 前提：設計要件書（`docs/design-requirements.md`）の第16章（法案と議席）、第17章（史実の知識への対策）
- 範囲：1990年末のゲーム開始から2026年まで。**章や史実の時期に縛られず、条件を満たせばいつでも起きる**
- 各章のイベント設計に出てくる消費税のイベント（第2章のE2-08、E2-19、E2-22など）は、この共通イベントが史実の時期に起きた場合の姿として書いている

---

## 1. 基本方針

| ID | 要件 |
|---|---|
| TX-R1 | 消費税の税率は **3%・5%・10%** の3段階を、ゲームの最初から用意する。1990年の開始時点は3% |
| TX-R2 | 税率を変えるイベントは、史実の時期に関係なく、条件（第3節）を満たせば起きる。史実より早く5%や10%に上げることも、ずっと3%のままにすることもできる |
| TX-R3 | 史実の時期は、乖離度（Z-6）の判定の基準としてだけ使う。史実より早い・遅い・違う税率を選ぶと、乖離度が上がる |
| TX-R4 | 引き上げは「決定」と「実施」の2つのイベントに分ける。決定から実施までの期間を選べ、実施の前に延期するかを判断する機会がある |
| TX-R5 | 引き下げ（10%→5%、5%→3%）も選べる。法案の重さは「中くらい」（16.2の消費税の減税） |
| TX-R6 | 史実の8%（2014年）は独立した段階にしない。10%への引き上げを「2段階で上げる」選択肢として扱う（TX-2） |

史実の税率（乖離度の基準）：

| 期間 | 史実の税率 | 史実の出来事 |
|---|---|---|
| 1989年4月〜1997年3月 | 3% | 1989年に導入。1994年に5%への引き上げを決定 |
| 1997年4月〜2014年3月 | 5% | 1997年に実施。直後に景気が後退した |
| 2014年4月〜2019年9月 | 8% | 2012年に10%への2段階の引き上げを決定。10%は2度延期された |
| 2019年10月〜 | 10% | 食料品などは8%のまま（軽減税率） |

|---|---|---|---|---|

## 3. 起きる条件

税率を変えるイベントは、次の2つの入り口のどちらかで起きる。

### 3.1 大蔵省（財務省）から持ち込まれる（種類B）
| 条件 | 内容 |
|---|---|
| 財政 | 財政のゲージが一定以下になると、大蔵省が引き上げ案を持ってくる。しきい値は税率ごとに変える（5%への案は早く、10%への案は財政がより悪くなってから） |
| 高齢化 | 社会保障費の伸びが一定を超えると、「社会保障の財源」として案が出やすくなる |
| 立場 | プレイヤーの立場で関わり方が変わる（B-2）。新人議員は党の会議での発言と採決だけ、大臣（大蔵・財務）や党の幹部は案の中身を決められる、総理は出すかどうかを決められる |

史実の財政の推移のままなら、5%の案は1994年ごろ、10%の案は2010年ごろに出る（パラメーターが史実どおりなら史実の時期に起きる、14.1の種類B）。

### 3.2 プレイヤーが提案する
- 大臣（大蔵・財務）、党の幹部、総理になると、時期に関係なく自分から提案できる
- 新人議員でも、党の会議で「引き上げるべきだ」と発言することはできる（実現はしない。財政規律派の評価 ↑、党の支持率 ↓（小））
- 第1章（1990〜93年）は新人議員なので、TX-1は大蔵省から持ち込まれる形でしか起きない。プレイヤーにできるのは賛否の表明と採決だけ

## 4. 各イベント

### TX-1 5%への引き上げの決定
- 状況：大蔵省が「高齢化に備え、今のうちに税率を上げておくべきだ」と案を持ってくる。所得税の減税と組み合わせて、負担の増え方を和らげる案になっていることが多い。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 決める。実施の時期を選ぶ（決定から1〜3年後） | 財政 ↑↑（実施の後）、党の支持率 ↓（決定の時点で小、実施の時点で大） | TX-3につながる。期間が短いほど、景気を読みやすいが、準備の反発が大きい |
| 所得税の減税を先に行い、引き上げと組み合わせる | 景気 ↑（短期）、財政 ±（減税の分だけ効果が小さい） | 史実の1994年の形。減税をやめるときに負担が重なる（第2章のE2-22） |
| 社会保障の使い道に限ると約束して決める | 党の支持率の下落が小さい。財政の自由度 ↓（ほかの使い道に回せない） | 後で使い道を変えると「公約違反」になる（16.3の1.5倍） |
| （何もしない） | 変化なし | 財政が悪化し続け、数年後に再び案が出る |

- 第1章で起きた場合（1993年以前）：史実より早いので、乖離度 ↑。この時期は景気が急に悪くなっていく途中なので、実施の時期の判断が特に難しい
- 第2章で史実どおりの時期に起きた場合：第2章のE2-08として描く

### TX-2 10%への引き上げの決定
- 状況：TX-1と同じ。社会保障と財政の再建を一体で進める案になっていることが多い。与党だけでは議席が足りないときは、野党との合意が必要になる。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 一度に10%に上げる | 財政 ↑↑↑、党の支持率 ↓↓↓（実施の時点）、景気 ↓↓ | 反動が最も大きい |
| 2段階で上げる（まず8%、1〜2年後に10%） | 財政 ↑↑（段階的に）、反動が2回に分かれる | 史実の形。2回目の前にもTX-3（延期の判断）が起きる |
| 食料品などの税率を据え置いて上げる（軽減税率） | 党の支持率の下落 ↓（小さくなる）、財政の効果 ↓、事業者の負担 ↑ | 史実では2019年に導入。福祉を重視する連立相手に評価されやすい |
| （何もしない） | 変化なし | 国債が増え続け、国債費が予算を圧迫する（F-3） |

- 野党と合意して決めた場合：党の支持率の下落を野党と分け合える（下落 ↓）が、合意を破ると大きな反発（史実の2012年の「三党合意」がモチーフ）

### TX-3 引き上げの実施（延期の判断）
- 状況：実施の半年前に、景気の状態をもとに「予定どおり上げるか」を判断する。予測（D-2）では、反発の倍率（16.3）と、上げた後の景気の見通しが幅で示される。
- **史実の知識への対策の中心（第17章）**：予測は「その時点で見えている景気」を使うので、上げた後に悪くなる外からの衝撃（アジアの通貨危機など）は予測に入らない

| 選択肢 | 必要な条件 | 効果 | 連鎖 |
|---|---|---|---|
| 予定どおり上げる | ― | TX-5へ | ― |
| 延期する（1〜2年） | 求心力 中〜高（大蔵省と財政規律派が反対する） | 財政 ↓、大蔵省との関係 ↓、党の支持率 ↑（小） | 延期を繰り返すと、財政の信用 ↓（国債の格付けが下がるイベント） |
| 延期を争点に解散する（総理だけ） | 総理 | 党の支持率 ↑ | 選挙で勝てば延期に信任を得られる（史実の2014年、2016年がモチーフ） |
| 引き上げを取りやめる | 求心力 高 | 財政 ↓↓、党の支持率 ↑ | 「決めたことを守らない」として、次の増税の提案に必要な求心力が上がる |

### TX-4 引き下げ
- 状況：景気の悪化や選挙で、減税を求める声が強まる。野党が「消費税の減税」を公約に掲げることがある。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 一時的に下げる（期間を決める） | 景気 ↑、暮らしの実感 ↑、財政 ↓↓ | 期限が来たときに戻すことが、事実上の増税として反発を受ける |
| 恒久的に下げる | 景気 ↑、党の支持率 ↑↑、財政 ↓↓↓ | 社会保障の財源が足りなくなり、社会保障費の抑制のイベントが起きやすくなる |
| 下げない | 党の支持率 ↓（減税の世論が強いとき） | ― |

### TX-5 引き上げの実施と反動
- 実施の月の前に駆け込みの消費が起き、実施の後に反動で消費が落ち込む
- 反発の大きさは16.3の倍率で決まる（景気が悪いと2倍、次の選挙まで1年以内なら2倍、公約に反するなら1.5倍など）
- 同じ時期に、減税の打ち切りや医療費の負担増が重なると、反動が大きくなる（史実の1997年）

## 5. 各章での現れ方（史実どおりの場合）

| 章 | 史実の時期 | 章のイベント |
|---|---|---|
| 第2章 | 1994年11月：5%を決定 | E2-08（TX-1） |
| 第2章 | 1996年6月：予定どおり上げると確認 | E2-19（TX-3） |
| 第2章 | 1997年4月：5%を実施 | E2-22（TX-5） |
| 第6章 | 2012年：10%への2段階の引き上げを決定 | TX-2 |
| 第7章 | 2014年4月：8%を実施／2014年・2016年：10%を延期 | TX-5、TX-3 |
| 第7章 | 2019年10月：10%を実施（軽減税率） | TX-5 |

- 史実より早く税率を変えた場合、その章のイベントは起きない（例：第1章で5%にしていれば、E2-08、E2-19は起きず、E2-22は財政再建の部分だけが起きる）
- 史実より遅らせた場合、章のイベントは条件を満たした時期にずれて起きる

## 6. 未決事項

| 項目 | 内容 |
|---|---|
| 大蔵省が案を持ってくる財政のしきい値 | 税率ごとの値 |
| 税率ごとの効果の数値 | 財政、景気、党の支持率への効果の大きさ |
| 3%より下 | 消費税の廃止（0%）を選択肢に入れるか |
| 3段階以外の税率 | 7%（第2章の国民福祉税）や15%以上を扱うか |
