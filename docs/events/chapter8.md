## 1. 章の概要

### 1.1 テーマ
- 「椅子を誰に渡すか」の章。主人公は2026年に70歳になり、かつての父やドンと同じ「長老」の側に立つ。第1章の構図が反転して戻ってくる
- 父の裏金の亡霊が、派閥の裏金事件として表に出る。30年前に新人として見た光景を、今度は裁かれる側の長老として見る
- 感染症、戦争、円安と、外からの衝撃が続く。長老の力でできることと、できないことを知る
- 最後に、父の遺言「日本を沈めるな。だが、まず自分の椅子を守れ」に、主人公自身の遺言で答える

### 1.2 章の始まり方（第7章の結果で変わる）

## 2. メインクエスト：感染症と円安

外からの衝撃に、長老としてどこまで関われるかを試す3段階のクエスト。**第7章の緩和の規模と財政が、MQ-2・MQ-3の難しさを決める。**ルートAの選択肢は総理への進言になる（1.3）。

### MQ-1 感染症の初動（2020年2〜4月）
- 種類：A（外からの衝撃）。**V-11、Z-14、Z-15を守る**
- 描写の方針：感染者や亡くなった方の数を「得点」として見せず、通信簿にも載せない。内部では「流行の波の大きさ」として扱い、画面には医療のひっ迫や暮らしへの影響として抑えた調子で出す
- 流行の波の大きさは、全国一律の「防災力」（第5章の新型インフルエンザへの備えを含む）で変わる。事前の対策はできない（Z-15）
- 4つの段階に分かれる

#### 段階1 クルーズ船（2020年2月）
- 状況：感染が広がる外国籍のクルーズ船が横浜に着く。役所は船内での隔離を続ける方針だが、船内の感染は止まらず、海外のメディアが日本の対応を連日報じる。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 船内での隔離を続ける | 国際関係 ↓、党の支持率 ↓ | 史実どおり |
| 早く下船させ、陸の施設で隔離する | 財政 ↓、国際関係 ↑、人と時間を使う | 検査の体制が早く整い、段階3の流行の波が小さくなる |
| 入国の制限を一気に広げる | 国際関係 ↓、景気 ↓、党の支持率 ↑（短期）、産業ごとの状態（観光）↓↓ | 流行の始まりが少し遅れる |
| （何もしない） | 党の支持率 ↓ | 港の検疫に任され、史実に近い経過になる |

- 史実の選択：船内での隔離を続け、国内外から批判を受けた

#### 段階2 学校の一斉休校（2020年2月末）
- 状況：全国の学校に一斉の休校を求めるかを迫られる。子どもを介した感染はまだ分かっていない。働く親からは「誰が子どもを見るのか」という声が上がる。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 全国一斉の休校を求める | 暮らしの実感 ↓、景気 ↓（小）、党の支持率 ± | 史実どおり。学びの遅れが残る（技術力 ↓、長期・小） |
| 感染の多い地域だけ休校にする | 暮らしの実感 ↓（小）、党の支持率 ± | 地域の差への不満が出る |
| 休校とともに、親の休業の補償と学校のオンライン化を一気に進める | 財政 ↓↓、技術力（IT）↑、暮らしの実感 ± | E8-04（デジタル庁）の効果 ↑ |
| （何もしない） | 党の支持率 ↓ | 各地がばらばらに休校を決め、混乱が長引く |

- 史実の選択：準備の期間がほとんどないまま、全国の学校に一斉の休校を求めた

#### 段階3 緊急事態宣言（2020年4月）
- 状況：都市部で感染が急に広がる。法律に基づく宣言を出しても、外出の自粛や休業は「お願い」でしかない。経済界は影響を恐れている。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 都市部から宣言を出し、すぐに全国に広げる | 景気 ↓↓、暮らしの実感 ↓、党の支持率 ↑（短期） | 史実どおり |
| 早く全国に出し、休業への補償を手厚くする | 財政 ↓↓↓、景気 ↓↓（早く戻る） | 流行の波が小さくなる。財政の悪化がE8-10・E8-14の財源の議論を重くする |
| 宣言は出さず、検査と病床の拡大に集中する | 財政 ↓、景気 ↓（小）、党の支持率 ↓↓ | 防災力が低ければ医療がひっ迫し、結局宣言を出す |
| （何もしない） | 党の支持率 ↓↓ | 知事たちが独自に要請を出し、国と自治体がばらばらに動く |

- 史実の選択：4月上旬に都市部の7都府県に宣言を出し、中旬に全国に広げた

#### 段階4 給付金（2020年4月）
- 状況：党と財務省は、収入が減った世帯に30万円を配る案をまとめた。「対象が狭い」と批判が集まり、連立相手の中道党が全国民に1人10万円を配るよう強く求める。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 全国民に1人10万円を配る | 財政 ↓↓、党の支持率 ↑、中道党との関係 ↑ | 史実どおり。貯金に回る分が多く、景気 ↑ は小さい |
| 収入の減った世帯に絞り、手厚く配る | 財政 ↓、暮らしの実感 ↑（困っている世帯）、党の支持率 ↓、中道党との関係 ↓↓ | 中道党が次の選挙で協力を渋る |
| 消費税を一時的に下げる（TX-4。税率が5%以上の場合） | 財政 ↓↓↓、景気 ↑、党の支持率 ↑↑、乖離度 ↑↑ | 期限が来て戻すときに反発が起きる（TX-4の連鎖） |
| （何もしない） | 党の支持率 ↓↓、求心力 ↓ | 世論と中道党に押され、結局1人10万円になる |

- 史実の選択：30万円の案を閣議で決めた後に撤回し、全国民に1人10万円を配った
- 通信簿での答え合わせの例：「あなたは2020年に消費税を一時的に下げました。史実では全国民に1人10万円を配り、税率は変えませんでした」

### MQ-2 戦争と円安・物価高（2022年）
- 種類：A（侵攻）とB（円安への対応）の組み合わせ。第7章の緩和が大きいほど円安が深い

#### 段階1 北の超大国の侵攻（2022年2〜3月）
- 状況：北の超大国が隣国に侵攻し、主要国が一斉に制裁に動く。日本は北の資源開発に出資していて、天然ガスの一部をそこから買っている。資源の値段が跳ね上がる。

| 選択肢 | 効果 | 連鎖 |
|---|---|---|
| 主要国と足並みをそろえて制裁し、資源開発の権益は手放さない | 国際関係（対米）↑、国際関係（北の超大国）↓↓ | 史実どおり |
| 権益も手放し、最も厳しい制裁を科す | 国際関係（対米）↑↑、暮らしの実感 ↓（電気・ガス ↑↑）、景気 ↓ | 段階2の物価高が大きくなる |
| 制裁は最小限にとどめ、資源の確保を優先する | 国際関係（対米）↓↓、党の支持率 ↓ | 主要国の中で孤立し、E8-22（米国の関税）で不利になる |
| （何もしない） | 国際関係（対米）↓ | 遅れて制裁に加わる |

- 史実の選択：主要国と協調して制裁に加わり、避難民を受け入れた。資源開発への出資は維持した

#### 段階2 1ドル＝150円と物価高（2022年9〜10月）
- 状況：米国が急いで金利を上げる中、日銀の天野総裁は「緩和の継続が賃上げにつながる」と修正を拒む。円が売られ続け、ガソリンと食べ物の値段が上がる。賃金は追いつかない。
- 介入の金額を幅の中から選べる（V-7）

## 5. 2026年の終わり方

   ▼

### 5.2 称号の例（C-4）
複数の条件を満たした場合は、最も特徴的な1つを称号にし、他は副題として並べる。添え書きに遺言の言葉を出す（例：「椅子を渡した長老 ――『椅子は、渡すためにある』」）。

| 称号 | 結果の傾向（条件の例） |
|---|---|
| 平成の中興の祖 | 1990年代の金融危機を小さくし、国力が史実を大きく上回る |
| バブル延命の帝王 | 不良債権の処理を先送りし続け、財政と国力が史実を下回る |
| 人口を守った宰相 | 人口の窓（第3〜4章）に大きく投資し、出生率と総人口が史実を上回る |
| 令和のキングメーカー | 第8章の総裁選で、担いだ候補が3回以上勝った |
| 椅子を渡した長老 | P-8で子以外に渡し、しがらみとスキャンダルが低い |
| 三代の地盤を守った人 | P-8で子に継がせ、地元の支持が高いまま終わる |
| 最後のドン | P-8で自分が出続け、しがらみと求心力が高い |

| 史実の証人 | 乖離度が30未満 |
| 失わせなかった30年 | 国力、暮らしの実感、人口、財政のすべてが史実を上回る（最も難しい） |
