# 章に関係ない加点・減点イベント（ADD-01〜15、SUB-01〜15）

- 版：v0.1（2026年10月14日。ユーザーが別のAIで作った30件を、設計書の形にまとめた）
- 前提：イベントの役割タグ（`event-roles.md`）、パラメーター一覧（`parameters-list.md`）、設計要件書の14章
- 位置づけ：特定の章に属さず、**パラメーターの状態**で出る共通の部品。どの章でも条件を満たせば出る
- 本文（第2・3節）は、ユーザーが用意した文章を元にした。誤記の訂正と体裁の統一のほか、SUB-01・03・04・05・09・10は現実の事件に近い細部を言い換えた（5.5）。第4・5節は、まとめるときに足した
- 効果の ↑ ↓ の量は「後で決める」（`numbers-draft.md`）。「（何もしない）」は、各イベントの3番目の選択肢で、オートモードの基準になる（V-6）

---

## 1. 設計原則

| 種類 | 原則 |
|---|---|
| 加点（ADD） | 過去の投資の果実や好調時の追い風として発生する。「どのパラメーターに山分けするか」を選ばせる。甘い汁を吸う選択ほど `緩み` や `しがらみ` が上がり、数か月後の減点の呼び水になる |
| 減点（SUB） | 過去の汚い選択のツケ（`スキャンダル`・`しがらみ`）、長期政権の `緩み`、国家指標の悪化から発生する。「どの資源（金・人・支持率・求心力）を差し出して損切りするか」を選ばせる。**痛みを伴う正しい処置**を選ぶと `スキャンダル` が下がり、`改革派の評価` が上がる |
| 副次効果（第4節） | 無難に見える選択にも、遅れて出る副次効果を付ける（例：ADD-02の定率減税 → 財政が悪化 → 国債金利が上がる → 株価が下がる） |

## 2. 第1部：加点イベント（15個）

### ADD-01 政治資金パーティーの大盛況とノルマ超過分
- 発生条件：`党の支持率` 55以上、かつ `景気` 50以上、`資金調達力` が標準以上
- 状況：都内の老舗ホテルで開いた政治資金パーティーに業界団体や企業が詰めかけ、会場から人が溢れかえった。企業側は「景気回復の波に乗り遅れたくない」と競って券を購入し、集まった資金は目標の1.5倍に達している。秘書が「ノルマを超えた余剰分をどう処理しますか」と帳簿を持ってきた。
- 選択肢：
  1. 収支報告書に載せず、派閥の若手への「餅代（裏金）」として配る
     - 効果：`金` ↑↑、`求心力` ↑↑、`スキャンダル` ↑↑、`緩み` ↑
     - 遅れて出る効果：（中期）`政治改革を求める世論` ↑
  2. 全額を正式に計上し、自分の選挙区の組織固めに使う
     - 効果：`金` ↑、`地元の支持` ↑↑、`求心力` ↓（小）（独り占めへの嫉妬）、`緩み` ↑（小）
  3. 余剰分は受け取らず、党本部の金庫に納める（何もしない）
     - 効果：`党の支持率` ↑（小）、`改革派の評価` ↑（小）、`金` ↓（小）（会場費の持ち出し分）

- 状況：相次ぐ不祥事と政治改革の先送りに、最大のスポンサーである経済団体の会長が記者会見で苦言を呈した。「株主への説明がつかない。クリーンな仕組みができるまで、会員企業による政治献金とパーティー券購入の斡旋を凍結する」と通告され、党と派閥の台所が一気に火の車になった。
- 選択肢：
  1. 企業・団体献金の全面禁止（または厳格な上限設定）に踏み切り、クリーンな政党へ脱皮する（痛みを伴う処置）
     - 効果：`資金調達力` ↓↓、`求心力` ↓↓（族議員の反発）、`スキャンダル` ↓↓、`改革派の評価` ↑↑↑、`政治改革を求める世論` ↓↓
  2. 法人税の引き下げや規制緩和を手土産に、経済団体の幹部へ水面下で献金再開を懇願する
     - 効果：`資金調達力` ↑（小）（一部再開）、`しがらみ` ↑↑、`財政` ↓（小）、`改革派の評価` ↓↓
  3. 献金減を受け入れ、手元の蓄えを取り崩してしのぐ（何もしない）
     - 効果：`金` ↓↓、`資金調達力` ↓、`求心力` ↓

### SUB-13 歳出削減のしわ寄せによる「老朽インフラ崩落」事故
- 発生条件：`防災力` が低い、かつ `財政` 優先で公共事業・維持管理費を削っている状態
- 状況：「コンクリートから人へ」「無駄な公共事業の削減」を優先してきた結果、点検・補修が後回しにされていた幹線道路のトンネル（または橋梁・水道管）が崩落する事故が起きた。物流が寸断され、地方自治体や建設業界から「維持管理費まで一律に削った政府の人災だ」と批判が噴出している。
- 選択肢：
  1. 財政規律の方針を一部修正して非を認め、全国一斉の緊急インフラ点検・補修予算を組む（痛みを伴う処置）
     - 効果：`防災力` ↑↑、`財政` ↓（小）、`改革派の評価` ↑（素直な軌道修正への評価）、`産業ごとの状態（建設）` ↑
  2. 事故が起きた選挙区と周辺地域にだけ、特例の復旧補助金を重点配分して火消しする
     - 効果：`地元の支持` ↑、`金` ↓（見舞金・対策費）、`防災力` ±0（全国の老朽化は放置）、`しがらみ` ↑
  3. 「管理責任は地方自治体と道路会社にある」として国の責任を否定する（何もしない）
     - 効果：`党の支持率` ↓↓、`地元の支持` ↓↓、`防災力` ↓

### SUB-14 金融緩和の長期化による「急激な円安と物価高」の直撃
- 発生条件：`緩和の残高・出口の難しさ` が高い、かつ `物価の圧力` が高い
- 状況：長引く金融緩和と海外との金利差から歴史的な円安が進み、輸入食料品や電気・ガス代が毎月のように値上がりしている。輸出大企業は過去最高益に沸く一方、家計の実質賃金はマイナスが続き、スーパーの店頭では「卵も野菜も高くて買えない」と主婦層や年金生活者の悲鳴が渦巻いている。
- 選択肢：
  1. 中央銀行の利上げ（金融正常化）を容認し、住宅ローン金利上昇や株安の痛みを覚悟で物価と円安を抑える（痛みを伴う処置）
     - 効果：`物価の圧力` ↓↓、`緩和の残高・出口の難しさ` ↓↓、`景気` ↓（小）、`財政` ↓（国債利払い増）、`改革派の評価` ↑↑
     - 遅れて出る効果：（中期）`暮らしの実感` ↑（小）
  2. 金融緩和は維持したまま、巨額の予備費を使って電気・ガス・ガソリン代の補助金をばらまく
     - 効果：`暮らしの実感` ↑（小）（一時的）、`財政` ↓、`物価の圧力` ↑（小）（緩和放置のため根本解決せず）、`緩み` ↑
  3. 「円安は輸出とインバウンドにプラスだ」と強調し、政策は変えない（何もしない）
     - 効果：`暮らしの実感` ↓↓、`党の支持率` ↓↓、`産業ごとの状態（製造）` ↑（小）

### SUB-15 社会保障費の抑制をめぐる高齢層・医師会の総決起大会
- 発生条件：`社会保障費` を抑制した直後、または `高齢化率` が高く `財政` が厳しい状態
- 状況：膨張し続ける医療・介護費を抑えるため診療報酬と年金の伸びを絞ったところ、全国の医師会と高齢者団体が猛反発し、選挙区で「お年寄りを切り捨てる冷血政治家を落とせ」と総決起大会を開いた。投票率の高い高齢層の離反に、党内の議員たちがパニックを起こしている。
- 選択肢：
  1. 医師会や高齢者団体の前に自ら出向いて財政破綻の危機を説き、代わりに予防医療と現役世代支援へ踏み込む（痛みを伴う処置）
     - 効果：`地元の支持` ↓↓（短期）、`社会保障費` ↓、`財政` ↑（小）、`改革派の評価` ↑↑、`しがらみ` ↓↓
     - 遅れて出る効果：（中期）`年金の信頼` ↑（現役世代からの信頼回復）
  2. 特例措置として「高齢者への臨時福祉給付金」と「地域医療補助金」を裏で付け、矛を収めてもらう
     - 効果：`地元の支持` ↑、`社会保障費` ↑、`財政` ↓、`しがらみ` ↑↑、`改革派の評価` ↓↓
  3. 方針は変えないが、説明会への出席も避けて嵐が過ぎるのを待つ（何もしない）
     - 効果：`党の支持率` ↓↓、`地元の支持` ↓、`求心力` ↓（党内の動揺を抑えられない）

## 4. 副次効果（ユーザーの追加の要望）

> 例えば、ADD-02において無難だと思われる1を選択すると、財務が悪化し、国債金利が上昇し株価が下落、などのイベントが発生するなど、副次効果もある。

### 4.1 設計ルール

| ID | ルール |
|---|---|
| S-1 | 無難に見える選択（国民に配る、地元に配る、先送りする）にも、**遅れて出る副次効果**を付ける。「正解探し」にならないようにする（V-5、W-1、W-4） |
| S-2 | 副次効果は、いきなり数値を動かさず、**条件つきで起きる連鎖イベントの呼び水**にする。条件は国家の状態（財政、緩み、物価の圧力、金融の傷みなど）にする。状態が良ければ起きない |
| S-3 | 副次効果の発生は、選択から**中期（1〜2年後）**を目安にする。短期の効果は第2・3節の「効果」、副次効果は「遅れて出る効果」の延長として扱う |
| S-4 | 痛みを伴う処置にも小さな副次効果を付け、「正しい処置が完全に報われる」形にはしない（対策Cの考え方） |
| S-5 | 副次効果は、予兆で伝える（予兆は状態を変えない）。例：財務省の「国債の入札が不調気味です」 |
| S-6 | 副次効果が呼ぶのは、加点・減点イベントか、既存の幹（財政再建要求など）にする |

### 4.2 国債金利の扱い
ユーザーの例にある「国債金利」は、現行のパラメーターにない。**表示用の指標として足す**ことをおすすめする（`財政` と `緩和の残高` から計算する。財政が悪化し、緩和が弱まるほど上がる）。国債金利が上がると、財政の利払い（`spend`）、株価（日経平均）、住宅ローン金利（暮らしの実感）に響く。
