# イベントの役割タグ：幹・加点・減点

- 版：v0.1（2026年10月14日。ユーザーが用意した「イベントアイテム3種類」の案を、設計要件書の14章に合わせてまとめた）
- 目的：ストーリー必須の「幹」に、追い風の「加点」と逆風の「減点」を絡ませ、運任せでなく戦略の面白さにする
- 位置づけ：既存の4分類（A〜D、14.1）は「発生の仕方」。この3つは「**役割タグ**」で、直交する。1つのイベントが「種類B」かつ「減点」になれる
- 名前はすべて架空。被害者のいる出来事は政府の対応に絞る（V-11、V-12）。数値の量は「後で決める」（open-issues 第3節）ので、向きだけ書く

---

## 1. 3つの役割

| 役割タグ | 呼び名 | 役割 | 発生の仕方 | 選択で問うこと |
|---|---|---|---|---|
| `trunk` | 幹（ストーリー必須の分岐） | 章の本筋と歴史の転換点（北陽銀行、消費税、政界再編など）。通すには求心力・議席・金を要求する**関門** | 条件で出る（種類B）。外からの衝撃（種類A）の幹もある | 国の針路。どの道を選ぶか |
| `plus` | 加点（追い風・果実） | 過去の種まきの成果、好調時のご褒美、毒入りの誘惑 | 遅れて出る成功報酬、好調時の持ちかけ | **どう山分けするか**（どこに振り分けるか、リスクを取るか） |
| `minus` | 減点（逆風・請求書） | 幹で強い選択をした副作用、過去の汚い選択のツケ | 幹の直後、スキャンダルや緩みが高いとき | **どこで血を流すか**（どの資源で損切りするか） |

```
【加点（種まきの果実／甘い誘惑）】
   │ ↑ 過去の投資、好調時のご褒美
   ▼ │
━━ ● ━━━━━━━━━━ ● ━━  ← 幹（関門）
   │             ▲
   ▼             │ 資源・支持率が削られる
【減点（選択の副作用／過去の請求書）】
```

- 加点・減点は、無関係なランダムにしない。**幹の前後の行動と連動**させる（第2節）
- 「通したい直前に過去の請求書が直撃し、求心力が足りなくなる」といった、予定調和を壊すドラマを自然に生むのが狙い

## 2. 設計ルール

| ID | ルール |
|---|---|
| R-1 | 幹には「通すための条件」（求心力・議席・金など）を必ず付ける。条件に届かなければ、望む道は選べない（選択肢が灰色になる／別の道に落ちる） |
| R-2 | 減点の選択肢は、結果の数字だけでなく「**どの資源を犠牲にするか**」を選ばせる。3つの型：①金で消す（金↓↓、評判は維持）、②人を切る（人−1、求心力↓、評判は微減）、③居直る（金も人も守る、支持率↓↓↓） |
| R-3 | 加点の選択肢は、「金＋10」で終わらせず「**ボーナスの振り分け先**」を選ばせる。3つの型：①身内に配る（求心力↑↑、緩み↑）、②地元に還元する（地元の支持↑↑）、③将来へ再投資する（将来の成長↑↑、今の得はゼロ） |
| R-4 | 毒入りの加点（闇献金など）は、受け取り方の度合い（全額・上限まで・断る）を選ばせる。断ると資金は苦しいままだが、評判が上がる |
| R-5 | 全選択肢に、喜ぶ立場と怒る立場がある（V-14）。「何もしない」は必ず入れる（V-6） |
| R-6 | **緩みの法則**：加点で良い思いをすると、緩み・スキャンダルが上がり、数か月後に減点が起きやすくなる（W-9と同じ仕組み）。順風満帆で退屈な時間をなくす |
| R-7 | **正しい処置の見返り**：減点で「痛みを伴う正しい処置」（身内の更迭、自腹の補填）を選ぶと、資源は減るがスキャンダルが消え、「改革派」の評価が上がる。後の幹で世論の味方を得やすい |
| R-8 | 順調すぎるときの出来事（ST-1〜ST-6）は、減点の一種として扱う。「罰が来た」とは見せず、原因か備えを見えるようにする |
| R-9 | 史実にない加点・減点の選択は、乖離度を上げない（ST-6、Z-8と同じ扱い） |
| R-10 | 同じ月に出る加点・減点は、最大1件ずつ。連続して出すぎないよう冷却期間を置く（試作の `cooldown` を使う） |

### 2.1 オートモードとの相性（G-2）
- **加点**は、秘書の方針に任せて自動処理してよい（気持ちよく稼がせる）。ただし毒入りの加点（R-4）は、方針が「清廉」でなければ自動で受け取らず、時間を止める
- **減点**のうち致命的なもの（崖っぷち）は、時間を止めて「どう始末するか」を迫る。軽い減点は秘書の方針で処理する
- **幹**は常に時間を止める

### 2.2 データへの落とし込み（試作 `events.js`）
イベントの部品に、次の2項目を足す。

| 項目 | 内容 |
|---|---|
| `role` | `'trunk'`／`'plus'`／`'minus'`（省略時は従来どおり、役割なし） |
| `tie` | 連動先。例：`{ after: 'mq2', within: 12 }`（mq2の12か月以内に出る）、`{ needs: 'trunk:e113', lead: 60 }`（e113の前に蓄えが要る） |

エンジン側（`engine.js`）の変更は、緩みの法則（R-6）を `slack`（緩み）の加算と、減点の出やすさへの反映として足す程度で済む。

### 3.3 幹の関門（R-1）の例：E1-13 内閣不信任案と政権交代（1993年夏）
- ここまでに加点で金と求心力を蓄え、減点のダメージを抑えられていないと、望む道（残留／離党して新党／残って派閥を継ぐ）を選べない。選挙で落ちる場合もある
- 具体的な条件値（求心力、地元の支持、金の下限）は試作で決める

## 4. 連動の一覧（第1章）

| きっかけ | 次に出やすくなるもの | 結果 |
|---|---|---|
| MQ-2で公的資金を投入 | 減点 E1-M1（炎上）→ E1-M2（献金打ち切り） | 資金が苦しくなり、E1-M2で汚れた金に手を出すと、ドンの逮捕の際に傷になる |
| E1-02で国内に投資 | 加点 E1-P3（果実） | 振り分け先しだいで、求心力・地元・将来の成長が分かれる |
| 加点で良い思い（E1-P2、E1-P3の①など） | 緩み↑ → 減点 E1-M3（失言・不祥事） | 数か月後に請求書が来る |
| 減点で痛みを伴う正しい処置を選ぶ | スキャンダルが消える。改革派の評価↑ | E1-13で世論の味方を得やすい |
| 選挙の半年前 | 加点 E1-P1（敵失）、E1-P2（闇献金） | 選挙の戦い方（追い風か、資金か）を選ぶ |
