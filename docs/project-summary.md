## 1. ゲームの概要

- 1990年から2026年までの36年間、日本の政治家として国を動かす。主人公は1990年に34歳の新人議員で、2026年に70歳の長老になる
- 父の遺言「日本を沈めるな。だが、まず自分の椅子を守れ」に、36年かけて自分なりの答えを出す物語
- 史実は出発点と素材で、**レールではない**。選択と国の状態しだいで、起きる出来事も、国の行方も変わる。史実の出来事も起きないことがあり、史実にない出来事も序盤から起きる。史実どおりでないほうが面白いなら、面白さを優先する（設計要件書のSH-1〜SH-6）
- 勝ち負けは付けない。2026年の通信簿で、史実の基準線と比べる（Z-11）
- 名前はすべて架空。米国以外の国は言い換える。被害者のいる出来事は、政府の対応の選択に絞る

## 5. 設計の考え方（今回の議論で固まったこと）

### 5.1 イベントは筋書きではなく「条件で出る部品」
- イベントは日付ではなく、**条件**（国と党と自分の状態の値）で出る。日付で固定するのは、災害や外からの衝撃だけ
- 大きなイベントは、条件を満たさなければ起きない。早く手を打てば起きず、国はより発展する
- うまく対処しないと、悪い事態が重なり、より悪い状況になる
- ループは条件に任せる。「傷みが残っていれば再び出る」と書けば、何度でも繰り返せる
- ルート名は、こちらで付けるラベルにすぎない。実際には値の変化で別の部品が出るだけ

### 5.1.1 選択の場面で事情を見せる
- 選択を迫るときは、国の事情・国民の事情・企業の事情を並べる。実際の単位の数字（財政収支、成長率、失業率、倒産件数、日経平均、税収）と、立場ごとの言い分で示す（V-13、V-14）
- 選択肢の効果も、できるだけ実際の単位で書く（例：赤字 約+3兆円/年）

### 5.2 案件の状態（解決済みなら関連イベントを出さない）
| 状態 | 意味 |
|---|---|
| 未解決 | 関連イベントが条件しだいで出る |
| 解決済み | 関連イベントは出ない。ただし解決の代償（バッシングや資金不足など）は出る |
| 再燃 | 解決後に悪化した。関連イベントが再び出る |

- 試作では「金融不安」の案件に入れた。次は全案件に広げる

### 5.3 乖離度
- 史実と違う選択で上がり、下がらない。段階：0〜30 史実に近い、30〜60 ずれ始め、60〜100 別の歴史
- 「別の歴史」の流れ（Z-10）は、乖離度60以上に加えて、流れごとの条件で入る

## 8. 第1章の設計

- 期間：1991年4月〜1993年8月。新人議員から始まり、章の終わりに党が割れるかが分岐する
- メインクエスト：北陽銀行の不良債権（MQ-1 頭取の再訪、MQ-2 公的資金の早期投入論、MQ-3 北陽銀行の行方）
- 救済局面：公的資金の規模（1兆〜20兆円）を幅で選ぶ。逐次投入は効果が7割になる
  - ルート①：小さく入れる → 連鎖倒産 → 追加投入 → バッシング → やけくそ投入
  - ルート②：大量に入れる → 連鎖は止まる → バッシングと支持率低下 → 献金・パーティ収入の減少 → 資金枯渇
  - ルート③：破綻整理に切り替える
  - 早期に手を打てば、株価の底割れ自体が起きない
- 縦糸：E1-15 未完の手帳、E1-16 父の死の夜の真相
