## 2. 主人公

### 真壁 遼（まかべ りょう）
- 1990年時点で34歳。総合商社の鉄鋼部門の課長。ロンドン駐在から戻ったばかりで、政治とは無縁だった（U-1）
- 性格の初期値はプレイヤーの選択で決まるので、ここでは固定しない。物語上の素地として「数字に強く、人の機微に疎い」「父を好きではなかった」を持たせる
- 父との関係：政治にかかりきりの父に反発し、地盤を継がないと公言して商社に入った。遺言を受け取る場面（第10章のステップ0）で、初めて父の弱った姿を知る
- 名前は入力式（確定）。デフォルトは「真壁 遼」。姓は父と共通なので、変えると父の名前の表示も変わる。名前はパラメーターに影響しない

## 3. 父

### 真壁 龍三郎（まかべ りゅうざぶろう）
- 享年68。衆議院議員、当選11回。元建設大臣。ドン派の金庫番を長く務めた
- 選挙区は地方（11.2のデフォルト）。地元のゼネコン、北陽銀行、農協が後援会の柱
- 性格：豪放で人たらし。金は「集めて配るもの」と割り切る一方、国の行く末には本気で危機感を持っていた
- 遺言：「日本を沈めるな。だが、まず自分の椅子を守れ」。前半は父の本音、後半は息子への処世の忠告。この2つの緊張がゲームのテーマ（1.2）になる
- 遺したもの
  - 莫大な遺産（金）と地盤（地元の支持の初期値、E-6）
  - 裏金と闇献金のリスト（第10章のステップ2）。ドンや大手運送会社との金の流れも載っている
  - **未完の手帳**。父が死の直前まで書いていた、銀行の不良債権を早めに処理する構想のメモ。1991年7月の遺品整理で見つかり、MQ-2（公的資金の早期投入論）で「父も同じことを考えていた」と分かる（10.6）

### 父の死の夜（第1章の縦糸。確定）
- 父が倒れた赤坂の料亭での「密談」の相手は、ドンだった
- 密談の中身は、未完の手帳の構想（不良債権の早期処理）。ドンは反対していた
- この事実を知っているのは、料亭に付き添っていた仁科だけ
- 明かされる時期：E1-12（ドンの逮捕）の前後に、仁科の口から。仁科との関係が悪いと、週刊誌の記事として知ることになる
- 狙い：父を「古い政治家」として片付けさせず、父の遺志とドンへの感情に揺さぶりをかける。死因は病死のままとし、陰謀ものにはしない

## 4. 古参秘書（設計要件書の未決事項への回答）

### 仁科 源吾（にしな げんご）
- 61歳。父の秘書を30年務めた。肩書きは公設第一秘書。地元回りと金庫番を兼ねる
- チュートリアルの説明役（U-2）で、最初に抱える人材

| 人材カード | 値（仮） | 補足 |
|---|---|---|
| 能力 | 75 | 地元と選挙の読みは確か。国の政策は分からない |
| 専門分野 | 地元・選挙 | 地元の支持と献金の生産が多い（P-4） |
| 清廉さ | 40 | 裏金の実務をすべて知っている |
| 忠誠 | 70 | 最初は「父への忠誠」。主人公への忠誠は行動で上下する |
| 派閥 | ドン派 | ドンとも直接つながっている |

- 性格：慇懃で無口。帳面に細かく、すべてを記録する。感情を見せないが、父の遺影の前でだけ長く手を合わせる
- 口癖：「先生（父）なら、こうなさいました」。主人公を「若先生」と呼ぶ。主人公を認めたと判定されると、呼び方が「先生」に変わる（関係の変化を一言で見せる演出）
- オートモードでの方針：地元利益優先派（M-4）。委任すると陳情を通しやすく、汚れた選択を「必要悪」として選びがち（M-5）

### 本編での役割
| 時期 | 役割 |
|---|---|
| チュートリアル | 説明役。会社を辞めて地盤を継ぐよう頭を下げる |
| 第1章 | 最初の委任先。日常の案件（第4章）の多くは仁科経由で持ち込まれる |
| 第1章の終盤 | 父の死の夜の真相を知る人物（第3章） |
| 第2章以降 | 引退するか、残るか、去るかは関係次第（下記） |

### 解雇できるか
- **できる**。ただし代償がある
  - 地元の支持 ↓↓、後援会の献金 ↓（地元の人脈が仁科に付いて離れる）
  - 解雇された仁科は、裏金リストの写しを持ったまま去る。この写しが後で「裏切り」の火種になる
- チュートリアル中（U-5）と第1章の初登院までは解雇できない

### 裏切るか
- **裏切ることがある。ただしプレイヤーの選択の結果としてだけ起き、物語上の決まった裏切りにはしない**
- 裏切りは、仁科の「父への忠誠」が主人公への不信に変わったときに起きる。きっかけの例：

| きっかけ | 仁科の受け取り方 |
|---|---|
| 崖っぷちのイベントで「秘書に罪をかぶせる」（G-3）を仁科に向ける | 自分が切られた |
| E1-07・E1-11でドンを追及する、または見捨てる | 父の盟友への恩を仇で返した |
| 裏金リストを清算し、父の名前まで表に出す | 父の名誉を汚した |
| 仁科を飛ばして、早瀬や鬼塚ばかりに委任する | 自分は用済みにされた |

- 裏切り方（忠誠が下がるほど重い）
  1. ドンに主人公の動きを報告する（求心力の判定で不利になる）
  2. 辞めて地元に帰り、後援会の一部を連れていく（地元の支持 ↓）
  3. 裏金リストの写しを週刊誌か検察に渡す（スキャンダル ↑↑。予兆の段階を一気に進める）
- 逆に忠誠が高いまま崖っぷちを迎えると、仁科は**自分から罪をかぶると申し出る**。プレイヤーはそれを受けるか、断るかを選べる。受ければ仁科を失い、断れば別の代償を払う
- 仁科は「ドンとも通じている」二重の立場を持つ。ドンへの報告は、忠誠が高いうちは主人公を守るため（ドンの怒りを先回りして伝える）に、低くなると主人公を売るために使われる

## 5. 引き継げる秘書（第10章のステップ3）

1周目の選択肢は次の2人。2周目以降は顔ぶれが差し替わる（11.2の段階1）。仁科は全周回で固定とする。

### 早瀬 真理子（はやせ まりこ）＝清廉な秘書
- 28歳。父の私設秘書で政策担当。法学部を出て大蔵省の外郭団体にいたところを父が引き抜いた
- 能力 80、専門分野 財政、清廉さ 90、忠誠 50、派閥 なし
- 予測の幅を狭くする（ステップ4、D-3）。オートモードの方針は財政規律派
- 性格：正論を遠慮なく言う。仁科とは反りが合わない。主人公が汚れた選択を重ねると、忠誠が下がって辞めていく（裏切りではなく離反）
- 将来、大蔵省の人脈や改革派（御堂）とのつなぎ役になる

### 鬼塚 剛（おにづか たけし）＝汚れ役の秘書
- 45歳。元は県議の運転手。父の下で集金と裏方を担った
- 能力 55、専門分野 集金・地元、清廉さ 15、忠誠 80、派閥 ドン派
- 金を集める力が大きい。スキャンダルが上がりやすい
- 性格：粗野だが義理堅い。主人公に忠実で、汚れ仕事を自分から引き受ける。崖っぷちでは「罪をかぶる役」の最有力候補になる
- 仁科とは師弟関係。鬼塚を切ると仁科の忠誠も下がる

## 6. ドン

### 権藤 嘉平（ごんどう かへい）
- 76歳。党（民自党）の最高実力者で、最大派閥「権藤派」の会長。総理を何人も担いできた「キングメーカー」
- 父とは同期当選の盟友。父は権藤派の金庫番として、ドンの資金の流れを支えてきた
- 性格：好々爺の笑顔と、冷徹な計算の二面を持つ。人を金と恩で縛る。「政治は数、数は力、力は金」が持論
- 主人公の見方：最初は「龍三郎の忘れ形見」として可愛がり、神輿として担ごうとする。主人公が独自の動きを見せると、手のひらを返す
- 1周目の流れ（第1章）
  - E1-05（1991年10月）：総裁選で誰を担ぐかを決める
  - E1-07（1992年2月）：大手運送会社からの巨額献金が報じられる
  - E1-11（1992年10月）：議員を辞職。派閥の跡目争いが始まる
  - E1-12（1993年3月）：脱税の容疑で逮捕。隠し資産が見つかる
- 主人公との関わりの山場
  - 父の死の夜の密談の相手（第3章）
  - 裏金リストにドンの名前がある。リストを「使う」と、ドンとの貸し借りの道具になる
  - E1-07でドンを追及すると、ドンは「お前の父親も同じ穴の狢だった」と脅してくる
- 失脚を防げるか（確定）：**ドンの辞職（E1-11）は必ず起きる。逮捕（E1-12）まで進むか、主人公がどこまで巻き込まれるかは変えられる**（10.4）。献金の構造は父の代からのもので、新人議員には止められないため
- 史実のモチーフ：当時の党の最高実力者（役割のみ）

## 7. 党内のライバル

### 葛城 恒雄（かつらぎ つねお）＝古参の実力者
- 63歳。権藤派の事務総長。調整と根回しの名人で、表に立たない
- 能力 70、専門分野 国会対策、清廉さ 50、忠誠（主人公に対して）40、派閥 権藤派
- 性格：律儀で地味。約束は必ず守るが、約束しないことには一切手を貸さない
- 1991年夏ごろ「神輿に担いでやる」とすり寄ってくる派閥の長老（10.3）。求心力の仕組みを教える役
- E1-11の跡目争いの一方の候補。付くと派閥は保守派が握り、党は割れにくくなる
- 仁科とは古い付き合いで、仁科の忠誠が下がると葛城の側に流れる

### 御堂 隆一（みどう りゅういち）＝改革派の若手リーダー
- 51歳。権藤派の若手のエースで、ドンの秘蔵っ子と呼ばれてきた。選挙制度と政治資金の改革を掲げる
- 能力 85、専門分野 選挙・党運営、清廉さ 55、忠誠（主人公に対して）30、派閥 権藤派（のちに離脱）
- 性格：剛腕で、目的のためには恩人も切る。改革の理想は本物だが、権力への欲も隠さない
- E1-05で「別の候補を推す若手の動き」を率いる。E1-11の跡目争いのもう一方の候補
- E1-13で党を割る中心人物。主人公を新党に誘う。誘いに乗るかどうかが、第1章の最後の分岐（W-10）の入り口になる
- 主人公にとっては「味方にすれば最強、敵にすれば最も危険」な人物。第2章以降の政界再編でも中心にいる

### 西園寺 晃（さいおんじ あきら）＝同期のライバル
- 36歳。1990年2月の総選挙で初当選した1年生議員で、補選組の主人公とほぼ同期（わずかに先輩）。父は元外務大臣で、別の派閥
- 能力 65、専門分野 外交、清廉さ 60、忠誠 ―（同僚）、派閥 他派閥
- 性格：育ちが良く、人当たりが柔らかい。主人公を「同じ二世」として親しげに扱うが、ポスト争いでは容赦しない
- 役割：政務次官や部会長のポスト（1.2の表）を争う相手。主人公がポストを逃すと、西園寺が得る
- 2周目以降は別の顔ぶれに差し替えてよい人物

## 10. 選択によるパラメーターの変化

- ↑ ↓ の書き方は第1章イベント設計に合わせる（↑↑・↓↓は大きな変化）。具体的な量は未決（効果の数値）
- 人材カードの「忠誠」（15.3）だけは、しきい値と結び付けるために仮の点数で書く
- 主人公の名前（入力式）はどのパラメーターにも影響しない

| 引き継ぐ秘書に早瀬を選ぶ | −5 | ― |
| オートモードの委任先を仁科にしておく | 1年ごとに +5 | ― |
| 委任先を仁科以外にしておく | 1年ごとに −5 | ― |

| E1-07で捜査への協力や追及に回る | −20 | （同上） |
| E1-11で葛城に付く | +10 | （E1-11の表のとおり） |

| 仁科の忠誠 | 起きること |
|---|---|
| 80以上 | 崖っぷちのイベントで、仁科が自分から罪をかぶると申し出る。主人公を「先生」と呼ぶ |

### 10.2 仁科を解雇する・罪をかぶせる
| 行動 | 効果 |
|---|---|
| 仁科を解雇する | 人 ↓（仁科を失う）、地元の支持 ↓↓、献金 ↓。忠誠が25以下なら、解雇の直後に裏切りの段階3が起きる |
| 崖っぷちで仁科に罪をかぶせる（忠誠80以上で、申し出を受ける） | 人 ↓（仁科を失う）、スキャンダル ↓↓（予兆を0に戻す）。地元の支持 ↓（小） |
| 崖っぷちで仁科に罪をかぶせる（忠誠80未満で、主人公から命じる） | 仁科は拒む。忠誠は0になり、裏切りの段階3が起きる。スキャンダルは下がらない |
| 仁科の申し出を断る | 仁科の忠誠 +10。崖っぷちの別の選択肢（大金で揉み消す／議員辞職する）を選ぶ |

### 10.3 早瀬と鬼塚

### 10.4 ドンの失脚（辞職は必ず、逮捕は変えられる）
- 辞職（E1-11、1992年10月）はどのルートでも起きる
- 逮捕（E1-12、1993年3月）は、次のどれかを満たすと起きる。どれも満たさなければ逮捕は起きない

| 逮捕につながる条件 | 理由 |
|---|---|
| E1-07で主人公が捜査への協力や追及に回った | 党内から証言が出る |
| 裏金リストを「清算」した、または仁科が裏切りの段階3に達した | 父の裏金の記録が捜査の手がかりになる |
| 党の支持率が一定以下（値は未決） | 世論に押されて検察が動く |

- 史実の選択は「逮捕される」なので、逮捕を防ぐと乖離度 ↑

逮捕が起きた場合、主人公がどこまで巻き込まれるか：

| E1-07での選択 | 裏金リスト | スキャンダル |
|---|---|---|
| 擁護した | 使った | ↑↑↑（予兆を1段階進める） |
| 擁護した | 封印した／清算した | ↑↑ |
| 距離を置いた | 使った | ↑↑ |
| 距離を置いた | 封印した | ↑ |
| 距離を置いた | 清算した | 変化なし |
| 追及した | どれでも | 変化なし。党の支持率 ↑、ドン派からの求心力 ↓ |

逮捕が起きなかった場合：
- E1-12は「ドンの院政」に置き換わる。ドンは議員を辞めた後も、裏から派閥を動かす
- 政治改革を求める世論は弱まる：党の支持率の下落は小さく、E1-13で党が割れる確率が下がる
- ドンに借りを作ったことになる：しがらみ ↑↑、求心力 ↑（ドン派から）
- ドンは第2章以降も登場し、ポストや予算の要求を出してくる
