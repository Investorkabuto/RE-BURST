# 失わせない30年 設計要件書

> バブル崩壊から2026年まで、「失われた30年」を失わせないために政界を生き抜く歴史シミュレーション放置ゲーム

- 版：v0.8（設計姿勢「史実は出発点」と、選択の場面での事情の提示を追加。史実の時期・進行を前提にした要件を改訂）
- 状態：コアの骨格を確定。数値・詳細は未定（「18. 未決事項」を参照）
- 関連文書：章ごとのイベント設計は `docs/events/` にある（第1章：`docs/events/chapter1.md`、第2章：`docs/events/chapter2.md`、消費税（全章共通）：`docs/events/consumption-tax.md`）。主要人物の設定は `docs/characters.md` にある

## 1. コンセプト

### 1.1 概要
1990年末、日本経済の破綻（バブル崩壊）と、大物政治家である父親の急死が同時に起きる。プレイヤーは、父が遺した「莫大な遺産」と「日本経済の危機」の両方を背負い、弔い合戦で政界に入る。2026年までの36年間、自分の椅子を守りながら、日本の行方を史実から書き換えていく。

### 1.2 テーマ
- 父の遺言：「日本を沈めるな。だが、まず自分の椅子を守れ」
- 日本を良くしたい理想と、議席を守りたい保身との間の緊張
- 選挙は短期で結果が出るが、国力は数十年かけて決まる。この時間軸のずれによるジレンマ

### 1.3 設計姿勢：史実は出発点で、レールではない（2026年10月14日のユーザーの決定）
| ID | 要件 |
|---|---|
| SH-1 | 史実は、出発点（1990年の日本の状態）と、出来事の素材として使う。史実をなぞることは目的にしない。史実どおりでないほうが面白いなら、面白さを優先する |
| SH-2 | 史実の出来事も、条件を満たしたときだけ起きる。起きない、形を変える、時期がずれることがある（例：ドンの辞職、党の分裂、株価の底割れ） |
| SH-3 | 史実にない出来事（架空の事件、災害、社会現象）を、序盤から史実の出来事と同じ重みで混ぜる。乖離度が上がるほど、その割合が増える（Z-10） |
| SH-4 | 何もしなくても、史実どおりの日本にはならない。世界の条件は周回ごとに少しずつ違う（17章の対策B） |
| SH-5 | 史実の知識は手がかりにはなるが、答えにはならない（17章） |
| SH-6 | 選択を迫る場面では、国の事情・国民の事情・企業の事情を示す（V-13） |

### 1.4 ジャンルの位置づけ
- 「放置もできる歴史シミュレーション」
- 総プレイ時間には限りがある（終わりのない放置ゲームではない）
- 近い作品：Universal Paperclips、A Dark Room、Paradox系のリアルタイム戦略

## 2. 時間システム

| ID | 要件 |
|---|---|
| T-1 | ゲーム内の時間は、**ゲームを起動している間だけ**進む |
| T-2 | 未起動中は完全に止まる。オフライン報酬は一切ない |
| T-3 | 時間の速さは「一時停止」「等倍」「倍速」から選べる。最速モードでは**ゲーム内の1年＝現実の1分**（等倍の速さと中間の倍率は未定） |
| T-4 | 期間は1990年末から2026年まで |
| T-5 | 決断イベントは、手動モードでは時間を止めて発生する |

## 3. 操作モード

| ID | 要件 |
|---|---|
| M-1 | 「手動モード」と「オートモード」を切り替えられる |
| M-2 | 手動モード：決断イベントで時間が止まり、プレイヤーが選ぶ |
| M-3 | オートモード：委任先（秘書・派閥など）に設定した**方針プリセット**に沿って自動で選ぶ |
| M-4 | 方針プリセットの例：財政規律派／積極財政派／技術立国派／地元利益優先派 |
| M-5 | 自動で選ぶ処理は完全なランダムにしない。方針と委任先の性格で重みを付ける |

### 3.1 オートモードの安全装置
| ID | 要件 |
|---|---|
| G-1 | 失脚につながるリスクは、3段階の予兆として通知する（例：週刊誌が嗅ぎ回る → 検察が内偵を始める → 逮捕が目前） |
| G-2 | 崖っぷちのイベント（失脚の直前など）は、**オートモードでも必ず時間を止め**、プレイヤー自身に選ばせる |
| G-3 | 崖っぷちイベントの選択肢の例：秘書に罪をかぶせる（人を失う）／大金で揉み消す（金を失う）／議員辞職する（ゲームオーバー） |

## 4. 資源・指標

### 4.1 分類
| 種類 | 中身 | 性質 |
|---|---|---|
| 資源 | **金**、**人** | 増やして使う |
| 指標 | 支持率、党内での求心力 | 行動の結果として上下する。直接は使えない |
| 国家指標 | GDP、日経平均、人口、出生率、賃金、財政など | 史実との差分として計算する（第6章） |
| リスク | スキャンダル、しがらみ | 溜まると爆発し、資源や指標を失う |

### 4.2 基本の循環
```
金 ──雇う・囲う──▶ 人 ──集金──▶ 金
                    │
     ┌──────────────┼──────────────┐
     ▼              ▼              ▼
   支持率        求心力       委任（自動処理）
     └──────┬───────┘              │
            ▼                      ▼
      ポストの獲得           決断の自動選択
            │                      │
            ▼                      ▼
   政策（金と求心力を使う）   汚れた選択 → リスクが増える
            │                      │
            ▼                      ▼
   国家指標（史実との差分）   スキャンダル爆発 → 人が離れ、支持率が下がる
```

### 4.3 「人」の役割
| ID | 要件 |
|---|---|
| P-1 | 人には種類と性格がある（例：清廉な秘書、汚れ役の秘書、族議員、官僚、学者） |
| P-2 | オートモードでどの選択肢が選ばれやすいかは、委任先の性格で変わる |
| P-3 | 抱えている人材の質によって、予測の精度（第7章）と、技術投資の「窓」の見え方（第5.2節）が変わる |
| P-4 | 金を集める（後援会・献金）、票を集める、派閥の求心力を支える、という生産の役割を持つ |

## 5. 政策シミュレーション

### 5.1 予算配分
| ID | 要件 |
|---|---|
| B-1 | 一般会計を、実際の分類に近い項目に分ける |
| B-2 | 動かせる予算の範囲は、立場に応じて広がる（若手議員：陳情を通すかどうか → 大臣：担当省庁の予算 → 総理：全体の配分） |
| B-3 | 項目ごとに、効果が出るまでの時間が違う |

| 項目 | 主な効果 | 効果が出るまで |
|---|---|---|
| 社会保障 | 支持率（高齢層）、人口 | 短期〜長期 |
| 公共事業 | 地元の支持、短期の景気 | 短期 |
| 文教・科学技術 | 技術力、将来のGDP | 長期 |
| 防衛 | 外交イベントへの耐性 | 中期 |
| 地方交付税 | 地方の票、派閥の求心力 | 短期 |
| 国債費 | 削れない。借金が増えるほど膨らむ | ― |

### 5.2 技術投資の「窓」
| ID | 要件 |
|---|---|
| R-1 | 技術ごとに、史実に基づいた「投資の窓」（成功率が高い時期）を設定する |
| R-2 | 窓より早く投資すると、技術が未熟で失敗し、金を失う |
| R-3 | 窓より遅く投資すると、他国にシェアを取られ、得られる効果が小さくなる |
| R-4 | 窓の位置がどれだけ正確に見えるかは、人材の質で決まる |

技術の候補（窓の目安）：

| 技術 | 窓の目安 | 史実 |
|---|---|---|
| 第五世代コンピュータ | （早すぎた例） | 1980年代の国家計画が失敗した |
| 半導体 | 1990年代前半 | 日米半導体協定の後、シェアを失った |
| インターネット・IT | 1995〜2000年 | 出遅れた |
| 携帯電話・スマホ | 2000年代 | ガラケーで独自に進化し、スマホで敗れた |
| 太陽光・電池 | 2000年代 | 先行したが、中国に逆転された |
| EV | 2010年代 | 慎重だった |
| AI | 2015年〜 | 出遅れた |

### 5.3 国民負担率
| ID | 要件 |
|---|---|
| F-1 | 国民負担率（税と社会保険料の負担）を上げると、財政は良くなるが支持率は下がる |
| F-2 | 支持率への悪影響は、負担を上げた直後が最も大きい |
| F-3 | 負担を上げないと国債が増え、国債費が予算を圧迫する |

### 5.4 効果が遅れて出る仕組み
| ID | 要件 |
|---|---|
| L-1 | 政策の効果は、指標ごとに時間差を持って表れる |
| L-2 | 目安：株価・景気は数か月、賃金・財政は数年、人口・出生率は約20年 |
| L-3 | 長期の政策（少子化対策など）は、短期の支持率にはほとんど効かない |

## 6. 史実との差分モデル

| ID | 要件 |
|---|---|
| H-1 | 史実のデータ（GDP、人口、株価など）を、通信簿で比べるための基準線として持つ。ゲームの進行を史実に合わせるためには使わない（SH-1） |
| H-2 | プレイヤーの判断で生じた差分を、基準線に積み重ねて現在の値を計算する |
| H-3 | 何もしなければ、おおむね史実に近い方向（低成長、財政の悪化、人口の減少）に進む。ただし、細かい出来事や時期は史実と同じにはならない（SH-4） |
| H-4 | 史実の大事件は、史実をモチーフにした大イベントとして用意するが、起きるのは条件を満たしたときだけ（SH-2）。発生の仕方は第14章に従う |
| H-5 | 厳密な経済シミュレーションにはしない。「何かを上げれば何かが下がる」というトレードオフと、その結果として起きるイベントの連鎖で表現する（14.5） |

## 7. 表示

| ID | 要件 |
|---|---|
| D-1 | 結果は「数字」と「雰囲気のテキスト」の両方で表示する |
| D-2 | 決断の前には予測を、決断の後には結果を表示する |
| D-3 | 予測は幅のある数字で出す。幅の広さは人材の質で変わる（優秀なら「+0.4%」、そうでなければ「+0.1〜0.8%」） |

表示の例：
```
┌─────────────────────────────────────┐
│ 【陳情】地元の高速道路延伸           │
│  ▶ 予算を通す        −2.0兆円       │
│     GDP予測 +0.2〜0.6%               │
│     地元支持 ↑  財政 ↓              │
│  ▶ 見送る                            │
│     地元支持 ↓↓  派閥の長老が不満    │
└─────────────────────────────────────┘
        ↓ 決断後
  公共事業 GDP +0.4%
  ［ゼネコンが喜んでいるようだ］
```

## 8. 選挙

### 8.1 党の結果（議席数で段階的に決まる）
| 結果 | 議席の状態 | 起きること |
|---|---|---|
| 圧勝 | 単独で安定多数 | 予算・法案が通しやすい。求心力が大きく上がる |
| 勝利 | 単独で過半数 | 現状維持 |
| 辛勝 | 過半数割れ → 連立 | 連立相手の要求で予算配分が縛られる |
| 小敗 | 第一党だが政権を失う | 野党の連立工作次第で下野（1993年型）。短期間で返り咲ける可能性あり |
| 大敗 | 議席が激減 | 確実に下野（2009年型）。返り咲きまで数年かかる |

| ID | 要件 |
|---|---|
| E-1 | 選挙の結果は、支持率、景気の実感（手取りが増えたか）、不祥事、国民負担率の変化から決まる |
| E-2 | 下野すると、予算を動かす権限を失う。ゲームオーバーではない |
| E-3 | 下野している期間の長さは、議席の差と、人・求心力を使った連立工作で変わる |
| E-4 | 党が大敗すると、長老の落選や執行部の辞任で上の席が空く。派閥を乗っ取るチャンスになる |

### 8.2 自分の選挙区
| ID | 要件 |
|---|---|
| E-5 | 自分の選挙区の当落は、党の結果とは別に判定する |
| E-6 | 父の地盤（弔い選挙）によって、序盤は高い得票率が保証される |
| E-7 | 自分の選挙区で落選すると、失脚となりゲームオーバー |

## 9. 終わり方

### 9.1 2026年の通信簿（勝ち負けは付けない）
| ID | 要件 |
|---|---|
| C-1 | 2026年に到達すると、通信簿を表示する |
| C-2 | 主要な指標について、史実（灰色）と自分の歴史（色付き）を重ねたグラフを出す |
| C-3 | 史実と違う道を選んだ箇所を、分岐年表として一覧にする |
| C-4 | 結果の傾向に応じて称号を付ける（例：平成の中興の祖／バブル延命の帝王／人口を守った宰相） |

通信簿の指標の候補（史実の数値は概算。実装前に統計で確認する）：

| 分類 | 指標 | 1990年 | 史実の現在 |
|---|---|---|---|
| 経済 | 名目GDP | 約450兆円 | 約600兆円 |
| 経済 | 1人当たりGDPの世界順位 | 上位 | 30位台 |
| 経済 | 日経平均 | 2〜3万円台 | 4万円台 |
| 生活 | 平均賃金 | ― | ほぼ横ばい |
| 人口 | 総人口 | 約1億2300万人 | 1億2000万人台（2008年がピーク） |
| 人口 | 合計特殊出生率 | 1.54 | 1.1台 |
| 財政 | 政府債務（GDP比） | 約60% | 約250% |
| 国力 | 世界GDPに占めるシェア | 十数％ | 約4% |

「国力」は、上の指標を合成した点数として定義する。

### 9.2 ゲームオーバー
| ID | 要件 |
|---|---|
| O-1 | 失脚（落選、逮捕、議員辞職など）するとゲームオーバー |
| O-2 | ゲームオーバーでも通信簿を表示する。失脚した後の日本は史実どおりに進んだものとして2026年まで計算する |
| O-3 | 失脚するまでに打った政策の、遅れて出る効果（人口など）は残る |
| O-4 | 選挙のたびにオートセーブし、ゲームオーバー後は直前の選挙からやり直せる |

## 10. プロローグとチュートリアル

### 10.1 前提
| ID | 要件 |
|---|---|
| U-1 | 1周目の主人公は「世襲」の出自（第11章）で、それまで政治とは無縁だった人物（例：商社マン）。プレイヤーと同じく、政界の事情を何も知らない立場から始まる |
| U-2 | 父の**古参秘書**が説明役になる。この秘書は「人」のシステムで最初に抱える人材でもある |
| U-3 | チュートリアルの長さは約**5分** |
| U-4 | 1つのステップで教える仕組みは1つだけにする。説明文ではなく、物語の出来事を通して仕組みに触れさせる |
| U-5 | チュートリアル中はゲームオーバーにならない |
| U-6 | ゲーム内の期間は1990年12月〜1991年4月。ゴールは補欠選挙（弔い選挙）での当選 |
| U-7 | 技術投資、予算配分、下野、派閥の長老との駆け引きは、チュートリアルでは教えない。本編で初めて出てきたときに、その場で教える |

### 10.2 流れ
| # | 時期 | 出来事 | 教える仕組み | 目安 |
|---|---|---|---|---|
| 0 | 1990年12月 | 赤坂の料亭での密談中に、父が倒れたとの知らせ。葬儀に業界団体の幹部、大蔵省の官僚、後継の座を狙う派閥の議員が押し寄せる。古参秘書が「会社を辞めて、地盤を継いでください」と頭を下げる。遺言「日本を沈めるな。だが、まず自分の椅子を守れ」 | なし（演出のみ。スキップできる）。最後に父の執務室とステータスが表示される | 60秒 |
| 1 | 〃 | **弔い合戦の記者会見**。A「父の遺志を継ぎ、景気の防衛に命を懸けます」（派閥と献金のルート）か、B「痛みを伴う大改革の時代が来ます」（世論と改革のルート）かを選ぶ。どちらも「正解」に見えないようにする | **決断イベント**（時間が止まる。決断の前に予測、後に結果が出る） | 45秒 |
| 2 | 1991年1月 | 時間が動き出し、日経平均が下がり始める。机の引き出しから**裏金と闇献金のリスト**が見つかる。「使う／封印する／清算する」を選ぶ | **時間の速さの操作**、**リスク**と予兆の第1段階（週刊誌が嗅ぎ回る） | 45秒 |
| 3 | 1991年2月 | 後援会の再建。父の元秘書のうち誰を引き継ぐかを選ぶ（清廉なタイプか、汚れ役か） | **金で人を雇う循環**、人の性格 | 45秒 |
| 4 | 〃 | **地元ゼネコンの陳情書の束**。公約に入れるかどうかを決める | **予測の精度**（ステップ3で雇った秘書によって、予測の幅が狭くなることを見せる） | 45秒 |
| 5 | 1991年4月 | **補欠選挙**。弔い票で当選は確実だが、ここまでの選択で得票率が変わる | **選挙**、選挙ごとのオートセーブ | 30秒 |
| 6 | 〃 | 初登院。**オートモードが解禁**され、秘書に方針を委任できるようになる。そこへメインバンク頭取から直訴状が届く（「不良債権を抱えて、もう持ちません」） | **オートモード**と方針プリセット。チュートリアルが終わり、本編の最初のクエストにつながる | 30秒 |

合計：約5分

### 10.3 本編の序盤につなぐ要素
- メインバンクの不良債権問題（1991〜93年のメインクエスト）
- 派閥の長老が「神輿に担いでやる」とすり寄ってくる（1991年夏ごろ）。求心力の仕組みはここで教える

- 上部：金、人、支持率、求心力、日経平均、GDP
- 中央：執務室（最初は父の部屋で、遺影が飾られている）。机の上に案件の書類が積まれていく

## 11. 周回とランダム要素

### 11.1 基本方針
| ID | 要件 |
|---|---|
| N-1 | 1周目は、固定の内容のチュートリアル（第10章）を遊ぶ |
| N-2 | 2周目以降は、チュートリアルの代わりに「プロローグ」を遊ぶ。説明はなく、演出はスキップでき、長さは1〜2分 |
| N-3 | プロローグの決断（記者会見・裏金・秘書・陳情）は、周回ごとに内容が変わる |
| N-4 | 外からの衝撃（世界的な不況、大地震など）の時期は、史実を目安にするが、1周目からずれることがある。起きないことも、史実にない衝撃が起きることもある（14.4） |
| N-5 | 開始条件と出自を、通信簿に表示する（条件の違う周回どうしを比べられるようにするため） |
| N-6 | 「前回と同じ条件で始める」を選べる |

### 11.2 ランダム要素の3段階
| 段階 | 内容 | 難しさへの影響 | 解禁の時期 |
|---|---|---|---|
| 1：内容の差し替え | 父が倒れた場面、裏金の額と関わる相手、引き継げる秘書の顔ぶれ、陳情の中身、補選の対立候補 | ほぼなし | 1周目を終えた後（2026年到達またはゲームオーバー） |
| 2：開始条件 | 選挙区（地方／都市）、父の派閥の規模、遺産と負債の比率 | あり | 1周目を終えた後 |
| 3：出自 | 主人公がどのような経緯で政治家になるか（11.3） | 大きい | 通信簿の称号や条件の達成で、1つずつ解禁 |

選挙区の違い：
- 地方：地盤が固く当選しやすいが、陳情（公共事業など）が重い
- 都市：浮動票が多く、世論の影響を強く受ける

### 11.3 出自（段階3）
出自ごとに、資源の初期値、短いプロローグ（1〜2分）、固有のイベントが変わる。本編の仕組みと史実の流れは共通とする。

| 出自 | 強み | 弱み | 遊び方 |
|---|---|---|---|
| 世襲（標準） | 金と人が多い。弔い票で当選しやすい | 裏金などの負の遺産。若造として求心力が低い | 遺産を活かしつつ、しがらみを処理する |
| 叩き上げの新人（地方議員や秘書の出身） | リスクが低い。地元の人脈がある | 金が少ない。地盤が弱く、毎回の選挙が勝負 | 金と人を一から集める |
| 有名人（タレントやスポーツ選手） | 支持率が高い | 人が少ない。専門知識がなく予測の精度が低い。世論の上下が激しい | 人気を元手に、人材を集めて政策通になる |
| 官僚出身 | 予測の精度が高い。省庁の人脈がある | 支持率が低い。演説が下手で選挙に弱い | 政策の正確さで勝負し、選挙を乗り切る |
| 野党の新人 | 政権批判の追い風を受けやすい | 予算を動かす権限がない | 1993年の政権交代などの機会をつかんで与党を目指す |

| ID | 要件 |
|---|---|
| N-7 | どの出自でも、開始年は1990年に固定する |
| N-8 | どの出自でも、「日本を失わせない」という目的は共通。世襲以外の出自では、父の遺言の代わりに、その出自に合った動機を用意する |
| N-9 | 最初に作る範囲では「世襲」だけを実装し、他の出自は後から追加する |

## 14. イベント設計

### 14.1 イベントの4分類
発生の仕方は、**その出来事の原因を日本の政治家が変えられるかどうか**で決める。

| 種類 | 判断の基準 | 発生の仕方 | プレイヤーが変えられること |
|---|---|---|---|
| A：外からの衝撃 | 日本の政治では防げない（世界的な不況、大地震、感染症、史実にない災害など） | 史実の時期を目安に、ずれる・起きない・史実にないものが起きる（14.4） | 被害の大きさ、対応の良し悪し |
| B：政治・経済の結果 | 日本の政策や政局が原因（金融機関の破綻、大蔵省の解体、増税、政権交代など） | 条件で決まる。史実の時期は目安にすぎない | 起きるかどうか、時期、規模 |
| C：日常の案件 | 陳情、怪文書、週刊誌の取材、長老からの呼び出しなど | ランダム。パラメーターによって出やすさが変わる | すべて |
| D：制度上の行事 | 予算編成、参議院選挙など | 時期を固定（13.1） | 結果 |

### 14.1.1 イベントの役割タグ（幹・加点・減点）
発生の仕方（A〜D）とは別に、イベントに役割を付ける。ストーリー必須の「幹」に、追い風の「加点」と逆風の「減点」を連動させる。詳しくは `docs/events/event-roles.md`。

### 14.2 史実をモチーフにした抽象化
| ID | 要件 |
|---|---|
| V-1 | 大イベントは実名で出さず、状況として描く（例：「アメリカの大手証券会社が破綻し、米国政府は救済を見送った。日本としてどう対処するか？」） |
| V-2 | 選択肢は史実に縛られない。ただし、史実に裏付けのある選択肢を含める（例：破綻した証券会社の海外事業を日本の金融機関が買収する） |
| V-3 | 各イベントは「史実で日本が取った選択」を内部に持つ。プレイ中は表示しない |
| V-4 | 通信簿で「史実ではこう対処しました」と答え合わせを表示する |

### 14.3 イベントの型
| ID | 要件 |
|---|---|
| V-5 | 選択肢は基本3つ（積極策／別の手段／何もしない）。二択は正解探しになりやすいため避ける |
| V-6 | 「何もしない」は必ず入れる。オートモードの基準にもなる |
| V-7 | 金額などは、幅の中から選べる（例：為替介入の額を5兆〜50兆円の間で選ぶ） |
| V-8 | 遅れて出る効果を設定する（例：円高を放置すると、数年後に工場の海外移転で地方の雇用が減る） |
| V-13 | 選択を迫る場面では、国の事情・国民の事情・企業の事情を並べて示す。それぞれ、実際の単位の数字（財政収支〇兆円/年、失業率〇%、倒産 月〇件、日経平均〇円など）と、少し前との比較、その立場の人の言い分（大蔵省、街の声、経営者など）で表す。選択肢の効果も、できるだけ実際の単位で書く（例：赤字 約+3兆円/年、成長率 約+1%） |
| V-14 | 立場ごとの言い分は、互いにぶつかるように書く（国は締めたい、国民は支えてほしい、企業は投資してほしい）。どの選択肢にも、喜ぶ立場と怒る立場がある |

例：
```
【世界的な不況が突如発生し、猛烈な円高に】
1ドル＝85円 → 予測：半年後に75円
 ▶ 為替介入する   金額：[ 5兆円 ━━●━━━ 50兆円 ]
     円高を抑える効果（予測）：小〜大
     財政 ↓  米国との関係 ↓（介入額が大きいほど悪化）
 ▶ 金融緩和を日銀に求める
     効果が出るまで半年  国債の金利 ↓
 ▶ 何もしない
     輸出企業の業績 ↓↓  工場の海外移転が加速
     ［経団連の重鎮から電話が鳴り止まない］
```

その他のイベント例：
- 「とある半導体企業が倒産寸前」→ 政府として支援する／条件付きで支援する／支援しない。技術投資の「窓」（R-1）と連動し、窓を過ぎてから支援すると、金を失ったうえで結局倒産する

### 14.4 発生時期
| ID | 要件 |
|---|---|
| V-9 | 外からの衝撃は、史実の時期を目安にするが、1周目からずれることがある |
| V-10 | 外からの衝撃が起きるかどうか、時期、規模は周回ごとに変わる。史実にない外からの衝撃（架空の災害や国際的な事件）も起きる |
| V-11 | 災害は「起きるもの」として描く。プレイヤーにできるのは備えと対応（被害を減らすこと）だけとする。実際に犠牲者がいる出来事への配慮のため |
| V-12 | テロ事件のような出来事は、ゲームの操作対象にするかどうかを慎重に判断する |

### 14.5 トレードオフと連鎖
| ID | 要件 |
|---|---|
| W-1 | すべての選択に、プラスとマイナスの両方がある。何かを上げれば何かが下がる |
| W-2 | パラメーターが一定の値（しきい値）を超えるか下回ると、イベントが起きる |
| W-3 | イベントの結果がさらにパラメーターを動かし、次のイベントにつながる（連鎖） |
| W-4 | 良い政策にも副作用がある。成功が新しい問題を生む |

連鎖の例：
| きっかけ | 次に起きること | 結果 |
|---|---|---|
| 選挙資金が足りない | 裏金を作る | マスコミにばれて落選する（ただし予兆と最後の決断がある：G-1、G-2） |
| 優秀な議員を防衛大臣に任命する | 残りは力不足の議員しかおらず、農水大臣も力不足になる | 水産業が壊滅する |
| 健康寿命を延ばす政策を行う | 高齢者が増える | 社会保障費が増える |
| 社会保障費を削りたい | 党の勢力が足りない | 法案を通せない |
| 党の勢力が最大になる | どんな法案でも通せる | 緩みと驕りでスキャンダルが出やすくなる（W-9） |

### 14.6 政策の実行条件
| ID | 要件 |
|---|---|
| W-5 | 政策ごとに、通すために必要な党の勢力（議席・求心力）を設定する |
| W-6 | 反発の大きい政策（社会保障費の削減、増税など）ほど、必要な勢力が大きい |
| W-7 | 勢力が十分に大きければ、どんな法案でも通せる |

### 14.7 組閣と大臣
| ID | 要件 |
|---|---|
| W-8 | 人材は数に限りがあり、大臣のポストに配置する（組閣）。担当分野の事故や業界の問題は、その大臣の能力で起きやすさが変わる |
| W-8a | 大臣の能力と専門分野によって、その分野の政策の選択肢と効果が変わる（例：有能な財務大臣なら選べる財政政策が増え、効果も大きくなる。力不足の大臣では選択肢が限られ、予測の幅も広がる） |
| W-8b | 派閥の長老は自分の派閥の議員を大臣に推してくる。断ると求心力が下がる |

### 14.8 長期政権の緩み
| ID | 要件 |
|---|---|
| W-9 | 党の勢力が最大の状態が続くと、驕りや緩みでスキャンダルと世論の反発が起きやすくなる。勢力を最大にした後も緊張感が続くようにする |

### 14.9 離党と新党
| ID | 要件 |
|---|---|
| W-10 | プレイヤーは党を離れ、新党を作ることができる |
| W-11 | 離党・新党の機会は、特定の年に固定せず、条件で発生する（例：党の大きなスキャンダル、党の支持率の低迷、派閥の冷遇、政策をめぐる党内の対立） |
| W-12 | 新党を作ると、プレイヤーは党首になる。少数政党として連立の鍵を握るか、政権交代を狙うかを選べる |

### 14.6 順調すぎるときの出来事と語り部（2026年10月14日のユーザーの決定）
うまく行っているときにも、政治と関係のない出来事が起きる。ただし「うまく行ったから罰が来る」とは見せない。原因か備えが、プレイヤーに見えるようにする。

| ID | 要件 |
|---|---|
| ST-1 | 型1「成功が自分で生む問題」：好調そのものが原因で起きる（例：景気の過熱と歳出の膨張による物価の高騰 → 放置すると暴動）。条件で起き、予兆を先に出す |
| ST-2 | 型2「外からの衝撃」：政治では防げない（例：首都の大水害）。起きるかどうかは語り部が決め、被害の大きさは備え（隠れた値「防災力」など）で決まる。歳出の削減や、治水の予算を地元の道路に回す選択で、備えが下がる |
| ST-3 | 型3「両方の性質」：外からの衝撃に、政策が重なると深刻になる（例：冷夏の凶作 × 減反・輸入制限 → 米価の高騰。第2章のE2-03とつなぐ） |
| ST-4 | 語り部：大きな波乱（株価の底割れ、連鎖倒産、暴動、ドンの逮捕など）のない月が続くほど、型2の衝撃が起きやすくなる。上がるのは起きる確率だけで、被害の大きさは備えで決まる |
| ST-5 | 予兆は「備えの状態」を伝える（例：河川局「堤防の補強は計画の6割で止まっています」）。災害が来る時期は教えない |
| ST-6 | 史実にない出来事での選択は、乖離度を上げない |

## 16. 法案と議席

### 16.1 法案を通す条件
| ID | 要件 |
|---|---|
| K-1 | 法案ごとに「重さ」を設定する。重い法案ほど、多くの議席と高い求心力が必要になる |
| K-2 | 議席は与党（連立を含む）の議席の割合で判定する |
| K-3 | 議席が足りていても、求心力が足りなければ党内の反対派（族議員など）が造反し、法案が通らないことがある |
| K-4 | 衆議院と参議院で多数派が違う（ねじれ国会の）場合、参議院で否決された法案を通すには、衆議院の3分の2が必要になる |

| 重さ | 必要な議席の目安 | 必要な求心力の目安 | 法案の例 |
|---|---|---|---|
| 軽い | 過半数（50%） | 低 | 補助金、公共事業、業界の支援 |
| 中くらい | 安定多数（約55%） | 中 | 社会保障費の抑制、年金の改革、金融機関への公的資金の投入 |
| 重い | 絶対安定多数（約60%） | 高 | 消費税の増税、医療費の自己負担の引き上げ |
| 非常に重い | 3分の2（約67%） | 非常に高 | ねじれ国会での再可決 |

（数値は目安。調整は未決事項）

### 16.2 対象とする主な法案
| 法案 | 重さ | 主な効果 | 主な反発 |
|---|---|---|---|
| 消費税の増税 | 重い | 財政 ↑↑ | 景気 ↓、暮らしの実感 ↓、党の支持率 ↓↓ |
| 消費税の減税 | 中くらい | 景気 ↑、党の支持率 ↑ | 財政 ↓↓ |
| 社会保障費の抑制 | 中くらい | 財政 ↑ | 高齢層の支持 ↓↓、暮らしの実感 ↓ |
| 社会保障の拡充 | 軽い | 党の支持率 ↑、人口（長期） ↑ | 財政 ↓↓ |

1990年の時点で消費税は3%。税率の変更（上げ・下げ）を法案として扱う。3%・5%・10%の段階は最初から用意し、史実の時期に縛られずに起きる（`docs/events/consumption-tax.md`）。

### 16.3 タイミング
| ID | 要件 |
|---|---|
| K-5 | 国民の反発の大きさは、法案を通すタイミングで変わる |
| K-6 | 反発は時間とともに薄れる。選挙の直前に通した法案ほど、選挙の結果に大きく響く |
| K-7 | 選挙で「増税しない」と公約した後に増税すると、反発が大きくなり、さらに党への信頼が下がる |
| K-8 | 法案を通す前に、反発の大きさを予測として表示する（D-2） |

反発の大きさを変える条件（倍率は目安）：
| 条件 | 反発 |
|---|---|
| 景気が悪いときに増税する | 2倍。景気もさらに悪化する（史実の1997年に近い状況） |
| 次の選挙まで1年以内 | 2倍 |
| 公約に反する | 1.5倍。党への信頼も下がる |
| 選挙の直後（次の選挙まで3年以上） | 0.7倍 |
| 景気が良い | 0.7倍 |

## 17. 史実の知識への対策

史実を知っているプレイヤーは、何が起きるかも、何が失敗だったかも分かっている。「今の知識で1990年に戻れたら」という魅力は残しつつ、**答えを知っているだけでは簡単に勝てない**ようにする。

### 17.1 実現する力を難しさの中心にする
| ID | 要件 |
|---|---|
| Z-1 | 難しさの中心は「何をすべきか」ではなく「それを実現できるか」に置く |
| Z-2 | 正しい政策でも、権限（立場）、求心力、議席が足りなければ実行できない（B-2、K-1〜K-4） |
| Z-3 | 史実で正解とされる政策ほど、当時は強い反対があったものとして、実現に必要な条件を重くする（例：1992年の公的資金の早期投入） |

### 17.2 正解にも代償を付ける
| ID | 要件 |
|---|---|
| Z-4 | 史実の失敗を避ける選択にも、史実を知っているだけでは分からない代償を付ける（W-4の応用） |

例：
| 史実の失敗を避ける選択 | 代償の例 |
|---|---|
| 公的資金を早く入れる | 「税金で銀行を救った」という反発で次の選挙に負ける。銀行が国に頼りきりになる |
| 半導体に巨額を投資する | 米国との貿易摩擦が激しくなり、他の産業が報復を受ける |

### 17.3 乖離度（史実からのずれ）
| ID | 要件 |
|---|---|
| Z-5 | 史実からどれだけずれたかを表す「乖離度」（0〜100）を持つ |
| Z-6 | 乖離度は、史実と違う選択をするたびに上がる。上がる量は、そのイベントの重要度で変わる（各イベントが持つ「史実の選択」（V-3）と比べて判定する） |
| Z-7 | 乖離度は下がらない |
| Z-8 | 乖離度は画面に表示し、通信簿にも載せる |
| Z-9 | 乖離度が大きいほど、その後のイベントの時期・規模・中身が史実から大きく離れていく（乖離度が低くても、史実と同じにはならない：SH-4） |
| Z-10 | 史実にはない独自のイベントは、序盤から起きる（SH-3）。乖離度が大きくなるほど、その割合が増え、史実のイベントの一部が起きなくなったり、別のイベントに置き換わったりする |
| Z-11 | 通信簿で史実と比べる基準線（H-1）は、乖離度に関係なく史実のデータを使う |

乖離度の段階（境目の値は目安）：
| 乖離度 | 状態 | 起きること |
|---|---|---|
| 0〜30 | 史実に近い | 種類Bのイベントは、条件しだいで史実に近い時期に起きやすい。史実の知識が手がかりになる（答えにはならない） |
| 30〜60 | ずれ始めている | 種類Bのイベントの時期と規模がぶれる。種類Aのイベントは時期は変わらないが、日本への影響の大きさが変わる |
| 60〜100 | 別の歴史 | 史実にない独自のイベントが起きる。史実のイベントの一部が起きなくなる、または別のイベントに置き換わる |

序盤は史実の知識が手がかりになるが、歴史を大きく変えたプレイヤーほど、その後は知識が通用しなくなる。どの段階でも、史実と同じ展開は保証しない。

### 17.4 細部を伏せる
| ID | 要件 |
|---|---|
| Z-12 | イベントは実名で出さず（V-1）、規模も事前には分からないようにする |
| Z-13 | 予測には幅を持たせる（D-3）。2周目以降は時期が前後する（V-10） |

### 17.5 災害への備え
| ID | 要件 |
|---|---|
| Z-14 | 防災への投資は、全国一律の「防災力」として扱う。特定の場所や時期を狙った対策はできない |
| Z-15 | 実際の被災地を狙って備えるような攻略が成り立たないようにする（V-11の配慮のため） |
